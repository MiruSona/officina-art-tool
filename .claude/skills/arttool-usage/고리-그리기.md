# 고리 그리기 — 그리고 → 글로 읽고 → 그림으로 보고 → 고친다

PIL 길에서 **캐릭터 · 얼굴 있는 것**을 그릴 때 쓴다. 한 번 찍고 끝내지 말고 최대 3바퀴 돈다.
본보기는 `scripts/draw_char_loop.py` (32×32 `char_small`, 2바퀴를 실제로 돈다). 근거 설계는 `<ArtTool>/Docs/Design/2026-10-07-draw고리설계.md` 6절.

**무엇에 좋나** (2026-10-07 실측, `<ArtTool>/Docs/Research/2026-10-07-draw고리실측.md`) — **깨끗하게 마무리**하는 데 좋다(최종 외톨이 · 구멍 린트가 한 번 찍기의 ¼~⅙, 덮인 손 같은 숨은 결함을 격자 읽기로 찾는다).
**원본과 더 닮게 만들지는 못한다**(원본 베끼기 닮음 점수 차이 없음). 비용은 토큰 1.2~1.3배 · 시간 2.5배.

| 쓴다 | 안 쓴다 (한 번 찍기로 충분) |
| --- | --- |
| 캐릭터(`char_small` · `char_blob` · `char_parts`) · 얼굴 있는 소품 · 세부가 있는 아이콘(`prop_small`) | 타일(`tile_base`) · 이펙트(`fx_*`) · 램프 · `ui9_panel` · 움직임 가이드 |

## 준비 (한 번)

```python
c = Canvas(template="work/guide")              # template render 결과 폴더
for name in ("body", "cloth", "face", "hair"):  # 겹마다 자기 마스크 안에만 찍히게
    c[name].set_clip(load_mask("work/guide", c.template_name, name, c.size))   # <템플릿>_mask_<겹>.png
c.set_symmetry("x", layers=["body", "cloth", "face", "hair"])               # 왼쪽 반만 그리면 거울
```

**템플릿 없는 큰 캔버스**(예 60×120 옆모습) — 마스크 · 가이드가 없으니 clip 을 걸지 않고, 읽을 창은 64 칸 이하로 손수 나눈다.

```python
c = Canvas(size=(60, 120), layers=["body", "cloth", "face", "hair"], ramps=r)   # r 은 그리기-pil.md 의 Ramps 본보기
TOP, BOTTOM = (0, 0, 60, 60), (0, 60, 60, 120)                                    # c.to_grid(box=TOP, rulers=True)
```

스크립트는 **PowerShell 로 돌린다** — Git-Bash 는 `/c/...` 경로가 꼬이고 한글이 cp949 로 깨진다. 한글 출력이 깨지면 `$env:PYTHONIOENCODING="utf-8"`.

## 한 바퀴 5단계

| # | 하는 것 | 코드 |
| --- | --- | --- |
| 1 | 바퀴 시작 → 그린다. 큰 덩어리는 도형, 눈 · 입 · 장식은 격자 글 | `c.mark()` → `c["body"].box(*g.box("head"), …)` · `c.paste_grid("face", FACE, at=g.box("eye_box_l")[:2])` |
| 2 | 글로 읽는다 — 린트 줄과 **창 단위** 격자 | `c.lint().lines()` · `c.to_grid(box=g.box("head"), rulers=True)` |
| 3 | 그림으로 본다 — 둘 다 **Read 로 연다** | `c.preview_changed(f"work/loop_{n}.png")` · `c.preview("work/p.png", scale=8)` |
| 4 | 체크리스트 5개를 글로 답한다 (아래) | — |
| 5 | 고친다 — 바뀐 글자만 다시 붙이고 바뀐 칸 수가 생각과 같은지 본다 | `c.mark()` → `c.paste_grid(…)` → `c.changed()["layers"]["face"]` · `c.diff_grid()` |

격자 글은 범례 줄(`k #2A2238`) + 빈 줄 + 한 글자 = 한 칸이다. `.` 은 투명. symmetry 를 켰으면 **왼쪽 반만** 적는다.
**격자 글자는 대문자로 쓴다** — 캔버스 범례(`c.legend`)가 팔레트 색 · `to_grid` 로 읽은 색에 소문자 a 부터 차례로 글자를 준다. 같은 소문자를 다른 색으로 쓰면 「범례 글자 'k' 가 … 캔버스 범례에서 다르다」 오류가 난다(색이 26개를 넘으면 대문자도 찬다).

```python
FACE = "K #2A2238\nP #F09A9A\nM #62403D\n\nKK..\nKK..\n....\nP..M\n"   # 눈 2×2 · 볼 · 입(가운데 칸이 거울로 두 칸)
```

**체크리스트** — ① 실루엣이 한 색으로 읽히나 ② 눈 · 입이 가이드 줄(`g.y("eye")` · `g.box("mouth")`)에 있나
③ 램프 밖 색 0 (`lint.stray_color`, 팔레트가 있을 때만 돈다) ④ 외곽선 끊김 0 (마지막에만 본다) ⑤ 빛이 `c.light` 쪽인가 (그늘이 반대쪽에 있나).
템플릿 없을 때 ②는 원본(또는 그린 `preview`)과 눈으로 견줘 답한다. 원본 보고 그릴 때 ③은 팔레트를 `Ramps` 로 만들어 `Canvas(ramps=…)` 에 주거나, 쓴 색 목록을 손으로 확인한다.
색 수는 체크리스트가 아니라 `check` 의 `color_cap` 으로 본다 — selout 외곽선은 램프마다 어두운 색을 하나씩 더해 색 수를 늘린다.

**이렇게 보인다** — 1바퀴 `loop_1.png` 는 모든 칸이 바뀌어 칸마다 자홍 테가 둘려 색을 못 쓴다 — **1바퀴는 `preview` 만 봐도 된다**(얼굴 안 빈 칸 같은 흰 구멍은 거기서도 보인다). 2바퀴부터는 고친 칸에만 테가 둘려 「어디를 고쳤나」가 한눈에 보인다.

## 외곽선 (마지막 바퀴 안) → 끝낸 뒤

1. 외곽선을 **한 번만** 두른다 : `c.outline("selout", where="inside")` → `c.lint(outline_mode="selout").lines()` 로 끊김 · 새로 생긴 orphan 을 본다. 남으면 그 바퀴 안에서 고친다.
   `where` 기본값은 `outside`(모양이 한 칸씩 커진다 — 둘레에 여백이 있어야 한다). 템플릿 크기에 꽉 찬 캐릭터는 `inside`(가장자리 칸을 덧칠).
   `inside` 는 가장자리의 일부러 둔 칸(입 · 눈 흰 점)을 덮는다 — **세부 칸은 둘레에서 한 칸 안에 둔다.**
2. `c.save("work/set")` → SKILL.md 흐름표 5~8단계(`layers check` → `check` → `sheet` 를 열어 보기 → `layers export`) 그대로.

## 흔한 실수

| 실수 | 왜 | 이렇게 |
| --- | --- | --- |
| `c.lint(rules=[...])` 로 규칙을 고른다 | 규칙을 주면 symmetry 켠 겹의 `asym` 자동 켜기가 꺼진다 | 바퀴 안에서는 `c.lint()` 그대로. 꼭 고를 땐 `"asym"` 을 같이 넣는다 |
| 그늘 · 빛 띠를 symmetry 켠 채 칠한다 | 그늘이 양쪽에 생기거나, 거울을 끄고 칠한 뒤 다시 켜면 그늘 칸마다 `lint.asym` 이 뜬다 | 그늘을 넣을 겹은 `set_symmetry(None, layers=[…])` 로 끄고 **끈 채 둔다**(그 겹 asym 도 같이 꺼진다) |
| 그늘을 `box` 로 칠한다 | clip 안이면 `round_box` 가 깎은 모서리까지 다시 메운다 | `c[n].paint(band & c[n].mask(), 색)` — 이미 칠한 칸만 |
| 얼굴 자리를 본체로 채웠다고 믿는다 | 본체 마스크는 눈 · 볼 · 입 자리가 비어 있다. 거기는 face 겹이 채워야 한다 | 2단계 린트의 `lint.hole … N칸 구멍` 줄(합친 그림에서 테두리와 안 이어진 투명 덩어리)과 격자 창의 얼굴 안 `.` 를 같이 본다 |
| 중간 바퀴에서 외곽선을 두른다 | `outline` 은 symmetry · clip 을 안 타고, 다시 두르면 선이 두 겹이 된다 | 마지막 바퀴에 한 번만, 두른 뒤 `lint` 한 번 더 |
| 겹마다 선 색을 `recolor` 로 바꾼 뒤 `lint(outline_mode="solid")` | solid 는 한 색 선만 이어진 것으로 봐 전부 끊김으로 센다 | 선 색을 겹마다 바꿨으면 `outline_mode="selout"` 으로 검사 |
| 작은 부위(손)가 안 보인다 | 같은 겹에서 나중에 칠한 것(바지)이나 위 겹(cloth)이 덮었다. 린트는 못 잡는다 | 칠한 순서 · 겹 순서를 본다. 몸 창 격자(`c.to_grid(box=…)`)를 읽어 손 칸이 있는지 확인 |
| 마스크가 부위와 안 맞는다(`char_small` 에 손 자리 없음 · 단발 옆 1px · 다리 한 덩어리) | clip 이 그린 칸을 잘라 버린다 | 그 겹은 clip 을 끄거나(`set_clip(None)`) 마스크를 넓힌다. 그때 `layers check` 의 `layer_mask` 경고는 무시해도 된다 |
| 64 넘는 그림을 통째로 `to_grid()` | 한 변 64 칸을 넘으면 거절한다(창도 같다) | `box=g.box("head")` 처럼 64 칸 이하 창으로 읽는다 |
| `L.arr[...] = ...` 로 칸을 직접 쓴다 | `dirty` 를 안 타서 `changed()` · `diff_grid()` 에 안 잡힌다 | 직접 넣은 뒤 `c.mark()` 로 그 상태를 새 기준으로 잡는다 |
| 팔레트 없이 `lint` 한다 | `light_guess` 가 `unknown` 이 잦다 — 검정 외곽선이 「어두운 쪽」을 먹는다 | 템플릿 · 램프를 준 캔버스로 린트한다(CLI 는 `--template`) |
| `lint.double` 이 떴다고 다 고친다 | 2px 대각선 끝을 잘못 잡을 수 있다(그래서 기본 꺼짐) | 좌표를 격자 창에서 보고, 선 끝이면 그대로 둔다 |

- `lint.orphan` 은 가장자리 칸 · 듬성한 겹(face)의 한 칸 점도 잡는다. 1바퀴의 볼 한 칸 점처럼 고칠 것이면 고치고, 눈 흰 점처럼 **일부러 둔 칸**이면 남기는 칸으로 뺀다 :
  `c.lint(waive=[(14, 12), (17, 12)]).lines()`(좌표는 예) — 보고에 「남기는 칸」으로 적는다.
- `c.diff_grid()` · `c.preview_changed()` 는 `mark()` 뒤 바뀐 칸이 없으면 오류다 — 고친 다음에 부른다.
- `c.changed()` 는 「값이 바뀐 적 있는 칸」을 센다. 칠했다가 원래 색으로 되돌린 칸도 1 로 센다.
