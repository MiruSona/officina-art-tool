# 두 덩이 그림의 빛 판정 변경 (6판 L)

- 설계 : `Docs/Design/2026-10-06-6판-템플릿넓히기·두덩이빛판정설계.md` 6장.
- **`style extract` 빛 판정이 덩이별로 바뀜 — 옛 프로필의 `style.light` 는 다시 뽑아 비교한다.**
- 무엇 : 무게중심을 「램프 덩어리 × 투명으로 떨어진 덩이(외곽선 포함)」 쌍마다 잡는다. 8칸 이상 · 가장 큰 덩이의 10% 이상만 덩이로 센다. 뜻 있는 덩이가 하나 이하면 티끌까지 옛 셈 그대로(보고 파일 · stdout 바이트까지 같음). 외곽선을 같이 쓰는 두 덩이는 못 가른다.
- 한 덩이 그림 : 옛 판과 판정 · `dx` · `dy` · `shift` 가 같다 (15장 폴더에 `style extract` 를 옛 · 새 소스로 돌려 출력 파일 4개와 stdout 이 같음을 견줘 확인).
- 두 덩이 그림 : 값이 바뀔 수 있다. 예 — 앞 덩이가 더 밝은 위 왼쪽 빛 그림이 옛 `bottom` → 새 `top_left`.
- 새 칸 : `estimate_light` 결과 `confidence`(high · low) · `pieces`, 요약 `light.low`(0 보다 클 때만 보고 파일에 실림), 경고 `light_mixed`. 덩이별 판정은 큰 덩이부터 64개까지.
- 왜 투명으로 나눴나 : 처음엔 검정을 뺀 칸으로 나눴는데, 선으로 갈린 한 캐릭터의 판정이 바뀌었다(세로선 1줄에 `top_left` → `top`, 격자에 `unknown`). 칸마다 도는 파이썬 루프는 2048 그림에서 0.45초 → 34초였고, numpy 라벨로 바꿔 0.59초가 됐다.
- 프로필은 사람이 붙이므로 옛 프로필이 저절로 바뀌지는 않는다.
