# 검은 테 다시 재기 (H6, 2026-10-12)

10-08 무거운 판 실측(`2026-10-08-로컬그림모델무거운판실측.md` 3절)의 H6 를, 제공자 `_upload` 를 고친 코드로 **같은 조건**에서 다시 돌렸다.

## 결론

- **검정 바탕은 사라졌다.** 10-08 엔 마스크 안 투명 칸을 모델이 「검정 바탕」으로 보고 검은 네모로 메웠다. 오늘은 흰 바탕으로 들어가 모델이 그 자리에 **물건(쇠판 · 쇠고리)** 을 그린다.
- 판정 수(`result_dark_in_newcells`)는 **118 → 20 (시드 1000) · 25 → 4 (시드 1001)**. 통과선 「0」에는 못 미친다.
- 남은 어두운 칸은 바탕이 아니라 **모델이 그린 쇠붙이와 외곽선**이다(그림으로 확인). 프롬프트가 「iron band · thick dark outline」을 달라고 하니 어두운 칸이 나오는 게 맞다. 지금 셈은 「바탕 검정」과 「그린 검정」을 못 가른다 — **셈을 고칠지, 이걸로 닫을지는 사람이 정한다.**
- 예상한 부작용도 나왔다 : 마스크 안 원래 투명이던 칸이 **불투명 흰색(또는 snap 이 누른 밝은 색)** 으로 돌아온다. 투명으로 되돌리는 건 `cutout` 몫이다.

## 4. 눈으로 본 것

비교판 : `~/.arttool/measure/heavy/out-1012/sheet_h6.png`(64px ×4, 마젠타 = 투명, 하늘색 네모 = 마스크) · `sheet_h6_raw.png`(raw 512).

- 10-08 : raw 바탕이 통째로 검정. 시드 1000 은 마스크 왼쪽 절반이 검은 네모, 1001 은 뚜껑 같은 원판 둘레가 검정.
- 10-12 : raw 바탕이 흰색. 시드 1000 은 통 왼쪽에 **어두운 쇠판(경첩 같은 것)**, 1001 은 **쇠고리 손잡이**를 그렸다. 어두운 칸은 그 쇠붙이 몸통과 외곽선이다.
- 마스크 안 나머지 투명 칸은 흰 네모(snap none) 또는 밝은 회색 네모(snap source)로 채워진다 — 설계상 예상한 부작용.

## 6. 재현

자료는 git 밖 `~/.arttool/measure/heavy/` (10-08 스크래치패드에서 복사, 원본 `out/` 그대로).

```powershell
cd ~\.arttool\measure\heavy
. .\env.ps1
.\measure.ps1 -Name H6-edge-s1000 -Kind inpaint -Spec .\spec_h6_edge.json -Seed 1000        # 결과 out-1012\<Name>\
.\measure.ps1 -Name H6-edge-nosnap-s1001 -Kind inpaint -Spec .\spec_h6_edge_nosnap.json -Seed 1001
python check_edge.py samples\barrel64_clean.png samples\mask_edge.png out-1012\<Name>\inpaint_000.png out-1012\<Name>\raw\inpaint_000_512.png
```

로그 : `out-1012/log/` (판별 로그 · `check_edge.txt` · 덧셈 `extra.txt`). 한 줄 요약 `out-1012/summary.txt`.
