## 1. 결론

- **새로 건진 것은 「수치가 있는 규칙」 열 남짓이다.** 대부분은 옛 문서와 같은 말이다(계단 규칙·AA 적게·색상 이동·외톨이 점 지우기).
- 쓸 만한 새 축 다섯:
  1. **크기별 외곽선 비중** — 1px 외곽선이 차지하는 넓이 비율이 4×4 75% → 16×16 23% → 64×64 6%. 작을수록 정보를 버려야 한다 (HG_EX).
  2. **땅에 닿는 외곽선 지우기 · 다리 끝 +1px** — 무게중심이 내려가고 바닥에 붙어 보인다 (undoknao).
  3. **AA 색 = 덮인 넓이** — 한 칸을 3×3 으로 보고 9/6/3/0 칸 덮임 → 100/67/33/0% 섞기. AA 는 선 한쪽에만 (mike14862838).
  4. **둥근 모양 만들기 절차** — 정사각형 → 네 모서리 깎기 → 바깥 가장자리 2점씩 더 깎기 → 둥글게 보일 때까지 (UenanJP).
  5. **애니 박자** — 같은 장수라도 간격으로 속도가 바뀐다. 3장 위아래 흔들림은 1-2-3-2 순환·장당 약 100ms, 다리부터 1px 씩 눌림 (logicsky_pixel 외).
- 계정 13개 중 **12개를 훑었다.** @saint11 X 전용 글은 못 봤다. 훑은 범위는 대부분 「인기」 탭 몇 화면이다 — 「최신」 탭은 거의 안 봤다.

## 4. ArtTool 에 쓸 것

### 코드로 잴 수 있는 규칙

1. **크기별 외곽선 경고** — 스프라이트 크기 n 으로 (4n−4)/n² 를 계산해 23%(16×16) 넘으면 「정보를 줄여라」 알림.
2. **땅 닿는 외곽선** — 캐릭터 스프라이트 맨 아래 줄이 전부 외곽선 색이면 알림(지우면 붙어 보인다).
3. **AA 양쪽 검사** — 한 외곽선 계단에 안팎 양쪽으로 중간색이 붙어 있으면 「한쪽만」 알림.
4. **렌즈꼴 타원 검사** — 타원 좌우 끝이 1px 뾰족하게 끝나면 알림.
5. **dither 면적 비율** — dither 무늬 칸이 한 색 덩어리의 몇 %인지 재서 대부분이면 경고. 띠 너비 대 덩어리 크기 비율도 함께.
6. **동심원 밴딩** — 색 경계가 서로 나란한 고리를 3겹 이상 만들면 경고(옛 「밴딩」 검사의 고리판).
7. **흑백 대비** — 팔레트를 명도로 바꿔 이웃 덩어리 명도 차가 너무 작으면 알림.
8. **애니 순환 검사** — 프레임 n 이 n−2 와 같으면 1-2-3-2 핑퐁으로 보고 표시. 장당 ms 가 80~120 밖이면 알려 주기(흔들림 한정).
9. **7×7 글꼴 틀** — 글꼴 셰이프의 최대 너비·높이가 모든 글자에서 같은지.

### 프롬프트·절차 팁

1. 그리기 전에 **램프·크기·빛 방향** 세 가지를 먼저 JSON 으로 받는다(HG_EX 맵칩 순서).
2. 음영은 「전체 그림자 → 빛 파내기」 순서로 시킨다.
3. 둥근 모양은 「정사각 → 모서리 깎기」 절차를 시킨다.
4. 색을 더할 때는 「형태를 나누는가」를 물어보게 한다(ENDESGA).
5. 손·끝부분은 끝으로 갈수록 붉게 그라데이션(0829_Misawa).
6. 애니는 장수보다 **간격 표**를 먼저 정하게 한다.
7. 정육면체 꼭짓점 방식을 하나 정해 프롬프트에 박는다.

### 사람 눈으로만

- 점선으로 남긴 곡선이 이어 보이는지.
- 외곽선 끝이 「멋있게」 뾰족한지.
- 튀김·소스처럼 재질이 그럴듯한지.
- 정보를 얼마나 버릴지(작은 스프라이트의 특징 고르기).
- 체력 UI 가 「읽히되 방해 안 되는지」.
