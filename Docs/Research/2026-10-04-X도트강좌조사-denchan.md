## 결론 먼저

- 이 계정의 X 게시물은 **긴 강좌가 아니라 「요령 한 줄 + GIF 한 장」** 꼴이다. 긴 설명은 YouTube 「ドット絵の学校」 영상으로 넘긴다.
- **GIF 가 본론이다.** 글은 한두 줄이고, 실제 공식(몇 px · 몇 프레임 · 겹 몇 장)은 GIF 안에 있다. GIF 26건을 프레임 단위로 뜯어 봤다.
- ArtTool 에 옮길 핵심은 셋이다.
  1. **이펙트 공식** — 16×16 · 5프레임 템플릿 4종, 반짝임 7프레임, 흙먼지 3프레임 같은 「크기 · 프레임 수 · 프레임별 모양」 표.
  2. **움직임 가이드 겹** — 천(옆으로 가는 원), 머리카락(위상이 밀린 점 4개), 오라(판 모서리 점)처럼 **가이드를 먼저 움직이고 모양을 따라 깎는** 방식.
  3. **겹 분해 합성** — 폭포 6겹, 폭풍 3겹, 레트로 화면 4겹, 판타지 배경 5겹. 색은 적게, 겹과 합성 모드로 입체감을 낸다.
- 코드로 잴 수 있는 것도 늘었다: 정수 배율 · 크기별 색 수 · 램프 모양 · 외곽선 색 · 축소 흔적에 더해 **루프 이음새 · 프레임 길이 · 광원 쪽 외곽선 밝기**.

## 2. 강좌 목록

- 파일은 `ArtTool/Docs/Research/도트강좌자료.local/` 에 있다 (git 무시). 그림 `<id>-1.jpg`, GIF `<id>.mp4`, 뽑은 프레임 `<id>-f<번호>.png`.
- X 는 GIF 를 mp4 로 다시 담으며 크기를 바꾼다. 아래 px 값은 「한 도트 = 화면 몇 px」 를 재서 나눈 값이라 **±1px 오차**가 있다.

## 3. 주제별 묶음

### 크기와 추상화
- 크기마다 그리는 법이 다르다. 8×8 은 기호, 16×16 은 눈 모양·볼, 32 이상부터 머리결·장식.
- 작은 크기는 1px 이 인상을 바꾼다. **눈은 2~3px 높이 카드 12종**처럼 모양으로 외워 둔다 (10-02).
- 초보는 16×16 부터. 이펙트도 16×16 · 5프레임부터.

### 그리는 순서
- **러프(일러스트) → 도트 선화(흑백) → 마무리(색 + 애니)** 를 크기와 상관없이 지킨다 (06-20 · 04-30 · 09-09).
- 러프는 대충, 세부는 도트 마무리에서. 소품도 연필 밑그림부터 (04-07).
- 러프는 **같이 일하는 사람과 모습을 맞추는 도구**이기도 하다. 16×16 얼굴 23개도 연필 칸 러프 → 도트로 옮겼다 (01-24 → 02-04).
- 축소만 하면 실패 — 인상만 남기고 다시 찍는다.

### 색 · 팔레트
- 색 수를 먼저 정한다. 연습 4색(청록 3단 + 바탕), 6색(세피아), 실전 28~50색 공용 팔레트.
- 공용 팔레트는 **색상별 세로 램프 5~6단** (09-30 의 31색 그림).
- 한 램프를 여러 재질에 돌려쓴다 — 크림색 하나로 백발·수염·해골·털 (09-22 인용 GIF).
- **바탕색도 팔레트 안의 한 칸**이다 (04-02 세피아 6색). 화면 전체를 한 톤으로 묶고 눈에 띌 것만 채도를 준다 (09-22 : 채도 있는 초상 둘).

### 외곽선
- 네 방식 : 없음 / 검정 1색 / 칠한 색의 어두운 색 / 어두운 색 + **광원 쪽만 밝게**.
- 완성본 대부분은 순흑이 아니라 부위별 어두운 색 (09-09 · 09-15).

### 표시 배율
- 정수배로만. 부드러운 확대는 뭉갠다 (06-23 썸네일 나쁜 예).

### 4-2. 생성 · 절차에 넣을 요령

- **이펙트 템플릿을 데이터로** : 3절 「프레임 공식」 표를 그대로 JSON 템플릿으로 둔다 (크기 · 프레임 수 · 프레임별 모양 · 색 수 · 프레임 길이). 생성 요청이 이 중 하나를 고른다.
- **움직임 가이드 겹 생성기** : 「점 N개 · 위상 지연 · 진폭」 만 받아 가이드 프레임을 찍어 주고, 그 위에 실루엣을 그리게 한다 (머리카락 4점 지연, 오라 판 모서리 점, 천 원 지나가기).
- **겹 분해 bake** : 겹별 PNG 와 합성 모드(normal · add · subtract 20% 등)를 받아 한 장으로 굽는다. 폭포 6겹 · 하늘 3겹 · 레트로 4겹이 시험 자료가 된다.
- **파츠 리그 절차** : 캐릭터를 파츠로 쪼갠 시트 → 대충 움직인 러프 → 다듬기 3단. 파츠 시트를 `anchors` 와 맞물린다.
- **그리는 순서 3단 강제** : 러프(일러스트) → 흑백 도트 선화 → 색·애니. 큰 크기만이 아니라 모든 크기.
- **크기별 추상화 지시** : 8px 「눈 = 1px 점」, 16px 「눈 카드 2~3px 높이」 처럼 크기마다 다른 문장.
- **팔레트 먼저 · 한 램프 여러 재질** : 생성 요청에 램프 JSON 과 「흰 램프를 머리·수염·뼈에 같이 써라」 같은 재사용 지시.
- **외곽선 방식 4택** : `none / black / selout / selout+light`.
- **곁가지 움직임 체크리스트** : 달리기에 흙먼지, 공격에 배경 흔들기, 결정 장면에 배경 번쩍임.
- **빠른 동작 템플릿** : 낙하는 사이 장면 0장 + 착지 첫 장 늘임, 물방울은 잔상 1장 + 튀김 약 7장. 같은 이펙트를 반복할 때는 튀는 모양을 몇 벌 두고 돌려 쓴다.
- **실루엣 먼저 생성** : 흰 1색 실루엣 프레임을 먼저 만들어 검사하고, 통과하면 색을 입힌다.
- **배경만 움직이는 GIF** : 정지 캐릭터 + 움직이는 배경 겹(사선 띠 · 별 · 도는 원)으로 짧은 반복 GIF 를 만든다.

### 4-3. 사람 눈으로만 되는 것

- 1px 차이로 바뀌는 표정·인상.
- 한 색으로 여러 재질이 읽히는지.
- 「색 · 선 · 정보량」 균형.
- 동작의 무게감(통통·묵직·말랑)이 의도대로인지.
- 연출 판단 (차렷 자세만인지, 너무 다 보여 주는지).
