# 재료 아이콘 시안 작업 피드백 (2026-09-20)

찹쌀이 농장 재료 아이콘 6종 시안을 PixelLab MCP + PIL 로 뽑으면서 본 것이다. ArtTool 명령은 이번에 안 썼다.

## 잘 된 것

- `create_1_direction_object` 에 `size 32` + `item_descriptions` 18줄(6종 × 3안)을 주니 **한 판 20 generations 에 여섯 종이 같은 화풍**으로 나왔다. 종마다 따로 뽑는 것보다 싸고 화풍이 맞는다.
- 설명에 「no outline」을 적어도 검은 외곽선은 안 나오고 **같은 색 계열의 어두운 테두리**만 나온다. PIL 로 「투명과 맞닿은 픽셀이 안쪽 이웃 밝기의 0.72 배보다 어두우면 지운다」 한 번이면 걷힌다. 테두리가 1px 빠지면서 32 → 28 안에 저절로 들어온다.

## 막힌 것 · 헷갈린 것

- **후보 그림 왼쪽 위에 번호 글씨(「9」「10」…)가 같이 구워져 나온다** (64장 묶음의 8번 뒤쪽부터). 왼쪽 위 구석(x<14 · y<9)에만 있는 덩어리를 지워서 풀었다. 그림이 그 구석까지 닿으면 이 방법은 못 쓴다.
- 안내는 30~90초인데 실제로는 **약 7분** 걸렸다 (get_object 의 ETA 472초가 맞았다).
- 두 번째 테두리 걷기를 같은 세기로 돌리면 대추처럼 알 사이 어두운 골이 뚫린다. 두 번째는 0.5 로 약하게.

## ArtTool 에 있으면 좋을 것

- 위 세 가지(번호 딱지 지우기 · 어두운 바깥 테두리 걷기 · N×N 가운데 맞추기)를 하는 `normalize` 쪽 아이콘용 옵션. 지금은 작업마다 PIL 스크립트를 새로 쓴다.

## 2판 결과 (같은 날 덧붙임)

- **위 AI 1판은 「화풍이 안 맞는다」로 버렸다.** 최종은 PIL 로 직접 짠 평평한 낱개 그림(장당 3~5색 · 그늘 한 단계)이다. 28×28 같은 작은 아이콘은 직접 짜는 쪽이 빠르고 농장 타일과 화풍이 맞았다.
- **ArtTool 은 이 흐름에서 끝까지 한 번도 안 거쳤다.** PIL 로 그린 PNG 를 Unity `Resources/Art/Ingredient/` 에 바로 넣었고, 임포트 설정은 게임 쪽 에디터 스크립트가 붙였다.
- 거칠 자리는 있었다 — README 의 `ui check`(최소 크기 · 램프 밖 색 · 반투명 · PPU 대조)가 아이콘 6장에 그대로 맞는 검수다. 다만 `ui icons` 는 **시트를 격자로 자르는** 입구라, 이미 낱장으로 나온 PNG 6장을 `ui check` 폴더로 들이는 길이 README 에서 안 읽혔다. 낱장 아이콘을 바로 받는 입구나 그 길을 알리는 한 줄이 있으면 썼을 것이다.
