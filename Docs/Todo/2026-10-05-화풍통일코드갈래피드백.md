
## 4판 (고른 것 적용) 에서 본 것

- `check` 의 `allow_alpha: binary` 는 프로필 통째 규칙이라, 유리처럼 **한 장만 반투명을 허락**하고 싶을 때 길이 없다. 파일 이름 단위 예외(예 : `check.alpha_except: [display_case]`)가 있으면 전체 검사에서 실패 1 이 계속 뜨지 않는다.
- 팔레트 정본(`mozzi_master.json`)에 종류별 선 색을 적을 자리가 없어 `kind_outline` 이라는 키를 손으로 더했다. 모르는 키는 그냥 지나가서 검사는 그대로 ok 였다.

## 한 개짜리 떡 굽기 (4-D5)

- 잘 된 것 : `arttool check --profile mozzi_icon` 이 22×16 짜리 작은 캔버스 11장도 그대로 받아 줬다 (실패 0).
- 헷갈린 것 : 가로가 홀수(21)인 그림을 가운데 피벗으로 찍으면 반 픽셀에 걸린다. 검사에 「가로 · 세로 짝수」 를 알려 주는 규칙이 있으면 굽기 전에 안다.
