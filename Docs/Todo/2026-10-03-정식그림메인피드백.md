# 정식 그림 메인 화면 — PixelLab 피드백 (2026-10-03)

> 게임 저장소의 v15 정식 그림(메인 화면 하늘 · 메뉴 아이콘) 갈래에서 쓰며 본 것. 상세 : 게임 저장소 `Docs/Reference/Art/정식/메인/README.md`.

## 잘 된 것

- `create_image_pro` 는 **576×384 같은 가로 캔버스**가 된다 (도움말상 16:9 는 688×384). 540 폭 배경을 이어 붙이지 않고 한 장으로 뽑았다.
- 프롬프트에 「flat even color #D4EEFA, no gradient」 를 쓰니 하늘 면이 **정말 한 색**으로 왔다 (14색). 위로 늘리기 · 카메라 배경색 맞추기가 쉬웠다.
- `create_image_pro_flash` 56×56 버튼은 **앞서 뽑은 버튼을 화풍 그림으로 주면** 틀 · 종이 면이 거의 같게 나온다.

## 막힌 것 · 헷갈린 것

- pro_flash 를 `no_background=true` 로 부르면 **버튼의 크림 종이 면까지 투명으로 뚫린다** (같은 프롬프트라도 씨앗에 따라). 메인 화면 v1 때와 같은 함정이다.
- `no_background=false` + 「solid teal background」 를 적었는데 **흰 바탕**으로 왔다. 모서리 flood fill 로 지울 수 있었지만 바탕색 지시는 안 듣는다고 보는 게 낫다.
- pro 의 값이 40회로 크다. 큰 배경 한 장이면 괜찮지만 다시 뽑기는 부담이다.

## 바라는 것

- 이 툴에 「모서리 flood fill 배경 지우기」 와 「외곽선 단색 맞추기(가장 어두운 색들 → 한 색)」 를 명령으로 두면 갈래마다 스크립트를 새로 안 짜도 된다.
