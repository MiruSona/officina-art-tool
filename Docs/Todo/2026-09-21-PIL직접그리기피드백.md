# PIL 로 직접 그리기 피드백 (2026-09-21)

게임 저장소에서 아이콘·타일·건물 그림을 **AI 생성기 대신 PIL 스크립트로 직접 그려** 확정한 판의 기록이다.

## 결론

- **작은 그림은 AI 보다 PIL 로 직접 그리는 쪽이 빠르고 화풍이 맞았다.** 지금 게임에 들어간
  재료 6장 · 농장 8장 · 건물 2장이 모두 PIL 산출물이고, AI 로 뽑은 아이콘 판은 「화풍이 안 맞는다」로 버려졌다.
  (찹쌀이 캐릭터만 다른 길이다)
- **그런데 이 길이 ArtTool 문서에 안 보인다.** 사용자가 2026-09-21 에 「PIL 이 뭐야?」 하고 물었고,
  그런 방법이 있는 줄 몰랐다고 했다. 그래서 이 문서를 남긴다.
- 바라는 것 : 안내서에 **「AI 로 뽑기 vs PIL 로 직접 그리기」 고르는 기준 표**와 본보기 스크립트 경로를 넣어 달라.

## PIL 이 뭔가

**Pillow(PIL)** 는 파이썬 그림 라이브러리다. `pip install pillow` 로 깔고 `from PIL import Image` 로 쓴다.
빈 그림을 만들어 **코드로 픽셀 하나하나에 색을 찍어 png 로 저장**한다.
즉 AI 생성기에 「이런 그림 그려 줘」 하고 맡기는 대신, **좌표와 색을 내가 정해 직접 그리는 길**이다.
ArtTool 은 이미 Pillow 를 의존성으로 쓰지만(`src/arttool/image.py`), 그건 **검수·합성용**이지
「그림을 처음부터 짜는 길」로는 문서 어디에도 안 적혀 있다.

## 잘 된 것 — 어떤 그림에 맞았나

| 그림 | 장수 · 규격 | 결과 |
| --- | --- | --- |
| 재료 아이콘 | 6장 · 28×28 | PIL 2판 D벌(밑색 + 그늘 한 단계 + 하이라이트 점)로 확정. AI 1판은 버렸다 |
| 농장 바닥 · 담장 | 8장 · 32×32 | 직접 짠 스크립트로 만들었다 (`Docs/Todo/2026-09-20-타일작업피드백.md`) |
| 건물 (합성소 · 가판대) | 2장 · 140×64 | PIL 3판으로 확정 |

**왜 맞았나**

- **화풍·색·크기가 정확하다.** 색표(`#F8BBC0` 같은 찹쌀이 색)를 코드에 상수로 박으니 다른 그림과 딱 맞는다.
  AI 는 「no outline」을 적어도 어두운 테두리를 넣고, 장당 색 수가 11~28색으로 튀었다.
- **숫자만 바꿔 다시 뽑는다.** 「그늘을 한 단계 더」「글자 띠를 18px 로」 같은 손질이 값 하나 고치고 재실행이다.
  AI 는 다시 뽑을 때마다 다른 그림이 나온다.
- **두 벌을 뽑아 나란히 보여 주기 쉽다.** 명암 없는 C벌과 2톤 D벌을 한 번에 굽고 비교 png 로 붙여
  사용자가 골랐다. 확정이 빨라진다.
- **빠르고 공짜다.** 재료 아이콘 6장 실측 — AI(PixelLab) 약 11분 · 20 generations vs PIL 약 3분 · 0 generations.

## 안 맞는 것

- **복잡한 캐릭터.** 찹쌀이 같은 몸·표정 그림은 손으로 좌표를 찍어서는 못 만든다. AI 나 손그림 쪽이다.
- **질감 · 자연물 · 많은 색.** 코드로 찍는 그림은 평평한 3~5색이 한계다.
- **장수가 많은 애니메이션.** 프레임마다 좌표를 잡는 값이 커진다.

눈금 : **28~64px 의 평평한 아이콘 · 타일 · 단순 설비 = PIL**, **캐릭터 · 질감 · 큰 그림 = AI**.

## ArtTool 에 바라는 것

1. **고르는 기준 표를 안내서에 넣어 달라.** `Docs/Guide/AI-그래픽-캐릭터-배경-가이드.html` 가
   「AI 로 만들 때의 안내」라서, 읽는 사람은 AI 말고 다른 길이 있는 줄 모른다.
   위 눈금(크기 · 색 수 · 캐릭터인가) 한 표면 충분하다.
2. **본보기 스크립트 경로를 적어 달라.** 처음 쓰는 사람은 빈 파일에서 시작하기 어렵다.
   아래 「근거 파일」의 세 스크립트가 그대로 본보기다.
3. **공용 도우미를 ArtTool 로 올려 달라.** 판마다 새로 짜고 있는 것들이다.
   - 그늘 계산 — 밑색에서 그늘색 · 하이라이트색을 만드는 함수 (지금은 손으로 16진수를 골라 적는다)
   - **×8 확대 비교 그림 만들기** — 낱장 여러 벌을 나란히 붙여 확대한 png. 사용자 판정에 매번 쓴다
   - 도형 찍개 — 타원 · 물방울 · 선 (`draw_v2.py` 에 있는 것)
