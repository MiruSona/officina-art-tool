# 화면 배경 작업 피드백 (2026-10-03)

> 게임 저장소에서 가게·합치는 화면 배경(360×800) 둘, 합성 기계 한 장, 연출 재료 셋을 만든 기록이다.
> 날짜 2026-10-03 · 쓴 사람 AI (그림 갈래 서브에이전트)

## 결론

**배경은 PixelLab `create_image_pixflux` 한 장(1 generation)씩 + PIL 손질로 끝났다.** 후보는 가게 3 · 합치는 화면 6 · 기계 5 장, `inpaint_image` 1번(약 40 generation)이다.
이 툴은 마지막에 `check --no-ramps` 만 돌렸고 두 폴더 다 종료 0 이었다.

## 잘 된 것

| 무엇 | 어떻게 |
| --- | --- |
| 실내 정면 뽑기 | 글머리에 「flat 2D side-scroller game background, flat elevation of one back wall only, no side walls, no ceiling, no perspective」 + `view=side`. 3장 중 1장이 완전 정면, 1장이 반쯤 정면 |
| 일부만 다시 그리기 | `inpaint_image` 에 `image_url` 로 앞 작업의 download URL 을 그대로 주고 사각형 마스크. 병이 있던 선반이 한 번에 시루·쌀자루로 바뀌고 바깥은 그대로였다 |
| 같은 씨앗 다시 쓰기 | 시안 때 씨앗(가게 2003 · 기계 1013)을 다시 쓰니 분위기가 이어졌다 |
| `wait_for_jobs` | 9장을 한꺼번에 걸고 기다리는 데 잘 맞았다 |
| 단순 도형 | 태극 반쪽·번쩍·반짝이는 PIL 로 그렸다. 태극 반쪽은 「180도 돌린 것과 겹치지 않고 원을 꽉 채우나」를 픽셀 짝으로 맞췄다 |
| `<툴> check` 낱장 모드 | 배경(360×800)·fx 폴더를 그대로 줘도 돌았다 |

## 막힌 것

| 무엇 | 어떻게 됐나 | 돌아간 길 |
| --- | --- | --- |
| 「straight-on front view … no isometric angle」만으로는 부족 | 합치는 화면 3장 중 2장이 아이소메트릭 방 | 위 「flat elevation」 글로 다시 뽑음 |
| 「no bottles, no jars」가 안 먹음 | 선반에 병이 나옴 | inpaint |
| `no_background=true` 인데 불투명 | 기계 5장 다 알파 255 에 흰 배경 | 모서리 flood fill (허용 오차 10) |
| 차양이 벽 소품을 가림 | 칠판 윗줄·시계 윗부분이 차양 밑에 묻힘 | PIL 로 차양을 올리고 칠판 윗부분·시계를 다시 그림 (여기에 가장 오래 걸렸다) |
| 360×800 이 한 번에 안 됨 | pixflux 는 한 변 400 까지 | 위아래를 PIL 로 연장 |
| `check` 보고의 한글이 Git Bash 에서 깨짐 | 화면 출력만 깨지고 JSON 파일은 멀쩡 | 보고 파일을 읽음 |

## 툴에 바라는 것

- 이 툴에 **배경 늘리기**(위아래 줄 복제·타일 이어 붙이기)와 **모서리 배경 빼기**가 있으면 PIL 스크립트를 매번 안 짜도 된다.
- `check` 에 「배경(불투명 큰 그림)」 모드가 있으면 색 수 규칙을 따로 줄 수 있다.
