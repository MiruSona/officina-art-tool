# 주방 기구 시안 v1 작업 피드백 (2026-10-05)

> 게임 저장소의 그림 갈래가 PixelLab 시안 12장을 뽑고 견줌판을 만들며 이 툴을 쓴 기록이다.
> 그림 : 게임 저장소 `Docs/Reference/Art/시안/주방기구-v1/`

## 잘 된 것

- `style ref --crop X,Y,W,H --canvas WxH --colors N --b64` 한 줄로 배경 조각 → 팔레트 PNG → base64 파일까지 끝났다. 1.2KB · 0.7KB 로 PixelLab 이 바로 받았다.

## 막힌 것

- **`cutout --key edge` 가 옅은 그러데이션 바탕을 못 지운다.** PixelLab 이 「solid teal background」 지시에 위 (187,217,217) → 옆 (123,168,179) 로 번지는 바탕을 줬다. `--tol 40` 에도 경고 `edge_left` 453칸만 내고 거의 그대로였다.
  - 바람 : 번지기를 「시작 색과의 차」가 아니라 **「이웃 칸과의 차」** 로 하는 선택(`--grow-local`)이나, **색상(hue) 범위로 지우기**(`--key-hue 160-200`). PIL 로 「파랑 − 빨강 > 12 인 칸을 가장자리부터 번지게」 했더니 깨끗했다.
- `cutout` 도움말에 그러데이션 바탕일 때 무엇을 쓰라는 말이 없다.

## 헷갈린 것

- 견줌판(배경 위에 여러 안을 제자리에 올린 통짜 화면 · 기구별 나란히 + 자리 상자)은 `sheet` 로 못 만들어 PIL 스크립트를 따로 썼다. 「배경 + 자리 표(JSON) + 안 묶음 → 화면 목업」 명령이 있으면 시안마다 스크립트를 안 써도 된다.

## 반복 07 주방 정식 그림 (2026-10-05 · 같은 날 뒷판)

### 막힌 것

- **틀 · 칸을 정해진 테두리 두께로 맞추는 명령이 없다.** 서랍장 틀(테두리 16px)을 칸 자리가 요구하는 10px 로 줄이려고, 같은 색이 이어지는 줄을 골라 빼는 PIL 스크립트를 따로 썼다. `extend canvas` 는 늘리기만 한다.
  - 바람 : `extend nine --in f.png --size 238x284 --border 10` 처럼 **9칸으로 나눠 가운데는 되풀이하고 테두리는 같은 색 줄을 빼서 맞추는** 명령.
- **청록 그러데이션 바탕 지우기는 이번에도 PIL 로 했다** (파랑 − 빨강 > 20 이면 지움). animate_image 결과에는 바탕 둘레에 더 짙은 청록 테두리 줄까지 끼어 `cutout --key corner` 로는 안 된다. 위 `--key-hue` 바람과 같다.

### 헷갈린 것

- `check` 의 `outline` 경고(selout+light · mixed)가 PixelLab 그림 24장에 다 걸렸다. 외곽선이 검정은 아니라서 `reline` 을 칠지 말지 경고만 보고는 판단이 안 됐다. 「이 판정이면 reline 하라 / 두어도 된다」 한 줄이 있으면 좋겠다.
- `ramp_shape` 경고는 프로필 램프 이야기인데 그림 묶음마다 똑같이 찍혀, 그림 경고처럼 읽혔다.

### 잘 된 것

- `check` 가 세 프로필(prop · bg · fx) 모두 한 번에 돌았고, 색 수 한도를 바로 확인할 수 있었다.
