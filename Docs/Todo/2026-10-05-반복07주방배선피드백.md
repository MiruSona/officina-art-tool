# 반복 07 주방 배선 피드백

> 2026-10-05 · 게임 저장소 반복 07 코드 갈래가 주방 정식 그림을 게임에 넣고 `check_all.py`(게임 쪽 스크립트 · 이 툴의 `check` 를 묶어 부름)를 돌린 기록.

## 잘 된 것

- 프로필별 묶음 검사가 새 그림 34장을 그림 갈래 README 의 경고 다섯과 똑같이 짚었다 — 두 갈래가 같은 숫자를 봤다.

## 헷갈린 것

- 같은 `--out` 으로 다시 돌리면 「이미 결과가 있다」 로 종료 2 인데, 그 문구가 Git Bash 에서 cp949 로 깨져 처음에는 까닭을 못 읽었다 (`PYTHONIOENCODING=utf-8` 을 줘야 읽힌다). 이것은 게임 쪽 스크립트 몫이지만, 이 툴 자체 출력도 Windows 콘솔에서 UTF-8 을 강제하면 같은 일이 안 생긴다.
- 「그림 갈래가 재고 둔 경고」 를 코드 갈래가 KNOWN 목록에 옮겨 적어야 「새로 생긴 것 0」 이 된다. `check` 보고에 「이 경고는 받아들임」 표시를 그림 쪽에서 남길 길(예 : 그림 옆 `.known` 메모)이 있으면 옮겨 적는 일이 없다.
