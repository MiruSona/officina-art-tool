# 정식 그림 농장 갈래 — PixelLab · 툴 피드백

> 2026-10-03 · 게임 저장소 v15 농장 정식 그림을 뽑으며 겪은 것. 짧은 메모다.

## 잘 된 것

- **gallery id 를 `style_image.source_image_id` 로 바로 줄 수 있었다.** 256 풀밭(62KB)을 base64 로 안 보내도 됐다. 이전 판에서 뽑은 그림은 `list_images(search=…)` 로 id 를 찾으면 된다.
- **`pixelart_workbench edit` 의 `copy_region` 넷으로 「반 칸 밀기」를 서버에서 했다.** 결과 URL(`/mcp/pixel-tools/<id>/image.png`)을 `inpaint_image_pro_flash` 의 `image_url` 로 그대로 넘겨 큰 base64 를 피했다.
- `inpaint_image_pro_flash` + 십자 가림판(16px)으로 이음매가 사라졌다. 바깥 픽셀은 그대로 남았다.
- `edit_image_pro_flash`(색 맞춤 켬)로 몸 테두리 선을 다시 그리게 했더니 **윤곽 픽셀이 하나도 안 바뀌었다** (64×64).

## 막힌 것 · 헷갈린 것

- **화풍 그림을 「전부 따름」으로 주면 「얼룩 없음」 글을 이긴다.** 세 씨앗 모두 옅은 얼룩이 들어왔다. `style_options` 에서 `detail` · `shading` 을 끄니 얼룩이 빠졌다 (대신 고른 벽지 무늬가 됐다).
- 바탕 있는 256 그림은 **네 변이 이어지지 않는다**(한 장은 이음매 값 1.88). 「seamless」 글만으로는 안 된다 — 밀고 inpaint 하는 손이 늘 필요하다.
- inpaint 로 고친 띠가 밝기 +2 쯤 밝게 왔다. 눈에는 안 보이지만 잴 때는 보인다.
- `get_balance` 의 남은 횟수는 **계정 전체**라 다른 세션이 같이 쓰면 이번 판 사용량을 못 가른다. 작업별 쓴 횟수를 돌려주면 좋겠다.

## 이 툴 쪽에 있으면 좋을 것

- 「2×2 로 깔아 이음매 값 재기」 · 「반 칸 밀기 + 가림판 만들기」 를 한 명령으로 (`tile seam` 같은 것). 이번엔 스크립트를 손으로 썼다.
- 「맨 바깥 1px 를 한 색으로」(선 색 맞추기) 손질 명령.
