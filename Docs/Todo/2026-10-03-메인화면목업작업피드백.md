# 메인 화면 목업 작업 피드백

> 2026-10-03 · 게임 저장소(ProjectMozzi2) 반복 03 에서 메인 화면 시안 두 안을 만들며 느낀 것.
> 한 일 : PixelLab 으로 건물·하늘·UI 조각을 뽑고 PIL 스크립트로 540×960 · 540×1200 목업을 합성했다.

## 결론

**이번 일에는 ArtTool 명령을 하나도 안 썼다.** 쓴 것은 ArtTool 의 `.venv` 파이썬(PIL · numpy)뿐이다.
목업 합성(부품 다듬기 → 배치 → 확대 → 글자)은 지금 ArtTool 에 맞는 명령이 없어 스크립트를 새로 짰다.

## 막힌 것

- **9조각 미리보기가 없다.** PixelLab 패널을 「이 크기로 늘리면 어떻게 보이나」를 보려고 9조각 함수를 직접 짰다.
  `ui frame` 은 코드가 그리는 패널용이고 `ui import` 는 `.9.png` 안내선이 있어야 한다.
  → 바람 : `arttool ui preview --in panel.png --border 26 --size 300x62 --out x.png` 처럼 border 숫자만 주고 늘린 그림을 보는 명령.
- **배경 지우기가 없다.** 바탕색을 깔고 뽑은 그림(버튼·구름·숲)의 바탕을 지우는 일을 세 번 했다 (색 한 값 지우기 · 모서리에서 번지며 지우기).
  09-20 재료 아이콘 피드백의 「뒤처리 옵션」과 같은 갈래다.
  → 바람 : `arttool cutout --in a.png --key corner|#RRGGBB [--tol N]`.
- **투명 여백 걷기도 매번 손으로 한다.** `ui icons --fit` 은 정사각형 아이콘만 받는다. 건물(144×146)처럼 네모가 아닌 그림은 못 넣는다.

## 헷갈린 것

- README 의 「아직 안 붙인 것」에 「PixelLab 은 이 PC 에 없다 · `--dry-run` 요청 JSON 까지만」이라고 적혀 있는데, 실제 작업은 PixelLab MCP 로 한다.
  **「그림 뽑기는 MCP 로, ArtTool 은 그 뒤 규격·검수」** 라는 한 줄이 README 머리에 있으면 처음 읽는 에이전트가 `provider make` 를 찾아 헤매지 않는다.
- 목업(시안)처럼 「게임에 안 넣는 그림」에도 `check` 를 돌려야 하는지 README 에 안 나온다. 이번에는 안 돌렸다.

## 잘 된 것

- `.venv` 에 PIL · numpy 가 이미 있어 따로 깔 것이 없었다. 저장소 뿌리에서 `Tools/ArtTool/.venv/Scripts/python.exe` 한 줄로 돌았다.
- 「겹은 캔버스를 안 자른다」 규칙 덕에 찹쌀이·손님 겹을 같은 좌표에 쌓기만 하면 맞았다.

## 다음에 해 볼 것

- 시안이 확정돼 UI 조각을 게임에 넣을 때 `ui import` → `ui check` 로 9조각 border 와 홀수·최소 크기를 검사한다 (이번 패널은 258×122 · 버튼 48×48).
- 부품표 굽기(이름·크기 딱지를 붙여 모으기)는 `recolor --sheet` 와 비슷하다. 아무 PNG 폴더나 받는 `arttool sheet --in parts/ --scale 2 --label` 이 있으면 스크립트가 준다.

## v2 작업에서 더 본 것 (2026-10-03)

- **막힌 것** : `create_topdown_tileset` 은 「muted · low saturation」을 적어도 풀이 형광 연두로 왔다. 타일 색을 지키게 하려면 pro_flash 에 색 값(#A6D49A)을 적어 뽑는 쪽이 맞았다. ArtTool 문서에 「타일 묶음은 색을 못 믿는다」 한 줄이 있으면 한 판을 아낀다.
- **막힌 것** : 가로 울타리를 160×32 한 장으로 뽑으면 기둥 간격이 37px 로 와서 32 격자에 안 맞는다. `arttool check` 에 「되풀이 단위가 타일 크기의 배수인가」 검사가 있으면 넣기 전에 걸린다.
- **잘 된 것** : `edit_image_pro_flash` 로 흰 몸에 회색 선·명암을 넣게 했더니 윤곽이 한 픽셀도 안 바뀌었다 (bbox 같음). 곱하기 색 겹을 지키면서 화풍을 바꾸는 길로 쓸 만하다.
- **다음에 해 볼 것** : 「흰 겹 × 색 곱하기」 미리보기를 `arttool recolor --multiply #hex… --sheet` 로 뽑을 수 있으면 이번 비교판 스크립트가 필요 없다.
