# 손님 옆모습 시안 피드백 (2026-10-03)

> 게임 저장소(ProjectMozzi2) 가판대 v6 시안을 만들며 PixelLab MCP 를 쓴 기록이다. 짧게 남긴다.

## 잘 된 것

- **`edit_image_pro_flash` 글 편집으로 방향 돌리기가 한 번에 됐다.** 128×160 큰 손님 앞모습 → 옆모습 · 3/4 뒷모습 넷 다 첫 판에 썼다. 키(145 · 151px)와 옷 · 머리 색이 그대로 왔다.
- 프롬프트 꼴 : 「Same character, same size, same art style, same outfit (옷 낱낱이), same hair. Change only the pose: …」. 옷을 낱낱이 적으면 색이 안 흔들린다.
- 한 장 6회. 넷에 24회.

## 막힌 것 · 헷갈린 것

- **`source_image_id` 는 그 판이 끝나기 전에 쓰면 「not found」 다.** 첫 판이 끝난 뒤에야 같은 id 로 다음 편집이 됐다.
- **돌려받은 `image_id` 와 `source_image_id` 가 같은 값이다.** 이 id 가 올린 원본인지 결과 그림인지 알 수 없다. 원본으로 다시 편집하려면 base64 를 또 보내야 하나 헷갈렸다.
- base64 를 넣으려면 그림을 파일로 인코딩해 읽어야 해서 문맥이 12KB 쯤 든다. 로컬 파일 경로를 받는 길이 있으면 좋겠다.
