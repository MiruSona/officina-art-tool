# 가판대 손님 3차 — PixelLab · ArtTool 쓰며 본 것 (2026-10-04)

> 게임 저장소의 옆모습 손님(120×240, 겹 넷)을 파츠별로 다시 뽑으며 적은 피드백이다.

## 잘 된 것

- **`edit_image_pro_flash` 로 「입히기 → 그 파츠만 남기기」 두 번이면 겹이 깨끗하게 나온다.**
  몸에 옷 · 머리를 입힌 그림을 다시 넣고 「그 파츠만 남기고 나머지 투명 · 잘린 자리 외곽선을 닫아라」 하면
  가장자리 외곽선까지 PixelLab 이 그려 준다. 겹쳤을 때 1 px 안쪽으로 맞고 부스러기가 0 이었다.
- 120×240 custom 크기에서 create · edit 모두 판당 9 로 고정이었다. 견적(`get_pro_flash_capabilities`)과 실제 잔액 차이가 정확히 맞았다.
- 받은 그림은 반투명 0 (알파 0/255) 이고 2 배 덩이도 아니었다 — 1 px 로 그려진다.
- 「색을 흰색~밝은 회색으로」 시키면 그대로 와서 곱하기 색 입히기용 원본으로 쓸 수 있다.

## 막힌 것 · 헷갈린 것

- **edit 은 모든 점을 조금씩 다시 칠한다** (「pixel for pixel 그대로」 라 써도 안 바뀐 점 0). 자리 · 모양은 지키지만 색이 미세하게 바뀐다.
  그래서 얼굴처럼 살 위의 작은 부위만 떼면 **딸려 온 살색이 몸과 달라 네모로 보인다.** → 머리통 전체를 한 겹으로 떼어 피했다.
- 「살색은 지우고 눈 · 입만 남겨라」 는 볼터치를 같이 지우고 눈을 뭉갰다. 작은 부위만 떼기는 약하다.
- 곱슬을 시키면 첫 판이 뾰족한 헝클 머리 · 외곽선 없음으로 왔다. 「round scallop bumps (not spikes)」 · 「closed solid dark 1-pixel outline」 을 넣자 됐다.
- `search_knowledge` 는 Phaser 지식만 있어 그림 파츠 나누기 요령은 안 나왔다.
- style 그림은 캔버스보다 크면 안 되므로 125 폭 주인 그림을 120×120 으로 잘라 16 색으로 줄여 넣었다 (base64 9 KB 는 잘리지 않았다).

## ArtTool 에 바라는 것

- 「겹 넷을 겹쳐 ×1 · ×4 로 늘어놓고 반투명 · 색 수 · 2×2 같은색 비율 · 떨어진 덩이를 재는」 검사를 명령 하나로 있으면 좋겠다. 이번에는 스크립트에 손으로 넣었다.
