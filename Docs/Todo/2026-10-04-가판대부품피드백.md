# 가판대 화면 정식 부품 작업 피드백 (2026-10-04)

게임 저장소 반복 04 에서 가판대 화면 부품(계산대 · 주인 · 진열장 · 옆모습 손님 겹 · 말풍선 · 버튼 틀)을 PixelLab 으로 뽑으며 겪은 것.

## 잘 된 것

- **키워서 다시 그리기** : ×2 굵기 시안 부품을 NEAREST 로 1.65 배 키워 `edit_image_pro_flash` 에 「이 크기의 1px 도트로 다시 그려라」 하면 같은 사람 · 같은 자세로 결만 고와진다. 한 판 6~9 크레딧. 주인 · 손님 · 진열장 셋 다 첫 판에 됐다.
- **inpaint 차이로 겹 떼기** : `inpaint_image_pro_flash` 는 마스크 밖을 한 점도 안 바꾼다. 몸(짧은 머리) 하나를 만들고 머리 · 얼굴 칸만 다시 칠한 판들과 차이를 뽑으면 머리 겹 · 표정 겹이 깨끗하게 떨어진다.
- 생성 판의 `download` 주소를 다음 inpaint 의 `image_url` 로 그대로 주면 base64 를 다시 안 보내도 된다 (토큰 절약).

## 막힌 것 · 헷갈린 것

- `create_image_pro` 계산대가 또 **캔버스 아래끝에서 잘려** 왔다 (배경 일감 때와 같은 버릇). 캔버스를 늘리고 아래 띠만 `inpaint_image` 로 채워 닫았다 — 처음부터 위아래 여백을 넉넉히 주는 쪽이 싸다.
- 머리 inpaint 가 마스크 안의 귀 · 뺨 살과 후드 깃까지 다시 그려서, 차이를 그대로 머리 겹으로 쓰면 머리색 바꿀 때 뺨이 물든다. 「옅은 살색 · 파란 옷 점은 머리 겹에서 뺀다」 거르기가 필요했다. 겹 떼기 도구가 생기면 「무엇을 머리로 볼지」 색 거르기를 옵션으로 두면 좋겠다.
- 시무룩 표정 inpaint 가 눈동자 색을 갈색 → 파란 회색으로 바꿨다. 「keep eye color」 를 프롬프트에 꼭 넣을 것.
- 잔액이 내 어림(약 147)보다 훨씬 많이(406) 줄었다. 판마다 「pricing_provisional」 로만 나와 실제 값을 알 수 없다. 판 끝에 실제 차감값을 알려 주는 길이 있으면 예산 지키기가 쉽다.
