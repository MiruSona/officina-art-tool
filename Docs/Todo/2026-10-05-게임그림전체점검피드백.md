# 게임 그림 전체 점검 피드백 (2026-10-05)

ProjectMozzi2 의 게임 그림 111장을 개선 판(e0f9c9e)으로 한 번에 잰 경험이다.
쓴 명령 : `style extract --by-folder --with-backgrounds` · `check --no-ramps [--mode background]` · `sheet --kinds zoom,silhouette,colors4,blur --label` · `template list/show/render --over`.

## 막힌 것

| # | 무엇 | 바라는 것 |
| --- | --- | --- |
| 1 | **템플릿이 정해진 크기만 받는다.** 120×240 사람 · 176×123 소품 · 540×440 화면 조각 · 56×54 9-slice 판은 종료 2 로 거절 | 크기 자유(가까운 틀을 늘려 그리기) 또는 「가장 가까운 크기 + 안내」 |
| 2 | **덩어리 캐릭터 틀이 없다.** `char_small 64` 는 기본 `tall` 사람 비율이라 둥근 몸(42×35) 위에 머리 상자가 뜬다 | `blob` 체형 (몸 · 얼굴 칸 · 바닥 줄) |
| 3 | **사람 겹 틀이 72×88 까지.** `char_parts` · `cycle_char` 에 120×240 이 없다 | 큰 사람 겹 · 걷기 틀 |
| 4 | **9-slice 판 · 작은 소품 · 64 섞임 연출 틀이 없다** (`fx_*` 는 16 위주) | 크기 자유 판 · 소품 틀 · 64 소용돌이 |
| 5 | `check` 의 `max_colors` 실패 `items` 에 **통과한 그림까지 들어 있다** | 실패한 것만, 또는 `ok` 칸 |
| 6 | `--mode background` 로 돌려도 **`max_colors` 상한이 48 그대로**라 540×1200 배경(64~68색)이 실패 | 배경 모드는 상한을 `color_cap` 표 값으로 |
| 7 | 프로필이 없으면 `outline` 은 판정만 적고 경고가 안 난다. 한 프로필에 `style.outline` 이 하나라 **종류마다 다른 외곽선을 한 번에 검사할 수 없다** (README 에서 종류별 칸을 못 찾음 — 추측) | 프로필 안 `kinds:` 갈래, 또는 폴더 → 프로필 짝 표 |
| 8 | `sheet` 가 한 배율이라 **25px 소품과 397px 조각을 한 판에 두면 소품이 안 읽힌다** | 칸마다 맞춤 배율, 또는 크기별 자동 나눔 |
| 9 | **바닥 맞춤 다시 깔기 명령이 없다** (bbox 를 캔버스 아래 −1 줄 · 가로 가운데로). 지금은 trim + extend canvas 두 번 | `pad --anchor bottom --margin 1` |
| 10 | `tint` 가 곱하기뿐이라 **색상 옮기기(색상 −10° · 채도 ×2)** 로 장식을 잔디 색에 맞출 수 없다 | `recolor --hue --sat --val` |
| 11 | 빛 판정이 **두 덩이 아이콘**(뒤 알 + 앞 단면)에서 「아래」 로 나온다 (8/17) | 덩이별 판정 또는 「믿기 낮음」 표시 |
| 12 | PowerShell `>` 로 `--json` 을 받으면 BOM 이 붙어 다른 스크립트가 못 읽는다 | `--out <파일>` 을 모든 `--json` 명령에 |

## 잘 된 것

- `style extract --by-folder` 한 번으로 9종류의 팔레트 · 견본 · 보고서가 나와 종류끼리 비교가 쉬웠다. 「보류」 까닭(외곽선 갈림 · 빛 갈림 · 장 수 모자람)이 적혀 있어 왜 못 묶는지 바로 알았다.
