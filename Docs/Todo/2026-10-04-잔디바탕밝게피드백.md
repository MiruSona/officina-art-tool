# 잔디 바탕 밝게 피드백 (2026-10-04)

게임 저장소 농장 잔디 바탕(256×256 이어 붙는 그림)의 색을 밝게 바꾸며 PixelLab MCP 를 쓴 기록이다.

## 막힌 것

- **workbench `edit` 결과 id 를 `inpaint_image_pro_flash` 의 `source_image_id` 로 못 쓴다** (「Image … not found」).
  대신 workbench 가 주는 다운로드 주소 `https://api.pixellab.ai/mcp/pixel-tools/<id>/image.png` 를 `image_url` 로 주면 된다.
- **style_image 를 base64 로 넣으려면 작게 잘라야 한다.** 256×256 png 는 base64 57KB 라 호출에 넣기 무겁다. 64×64 로 잘라 1.4KB 로 넣었다 (작은 화풍 그림은 가운데 놓인다고 문서에 있다).
- `create_image_pro_flash` 256×256 바탕 있음 결과의 **맨 왼쪽 1줄이 회청색 테두리**로 왔다. 반 칸 밀기 → 십자 inpaint 로 지워졌지만, 밀기 없이 쓰면 줄이 남는다.

## 잘 된 것

- 「색만 옮기기」(팔레트 일대일 바꾸기) 는 크레딧 0 으로 무늬 · 이음매를 그대로 지킨다. 색 문제만 있을 때는 이게 먼저다.
- 반 칸 밀기(workbench `copy_region` 넷) + 가운데 십자 16px inpaint 로 이어 붙는 바탕 만들기가 이번에도 됐다. 256 한 장 9 생성, inpaint 9 생성.

## 바라는 것

- workbench 결과 id 를 다른 PixelLab 도구가 그대로 받게 해 주면 좋겠다.
