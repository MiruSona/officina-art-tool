# 주인 작은 크기 작업 피드백 (2026-10-03)

> 가게 주인(128×160 확정 그림)을 손님 크기(64×80 급)로 새로 뽑으며 PixelLab MCP 를 쓴 기록이다.
> 결과 그림과 프롬프트는 게임 저장소 `Docs/Reference/Art/시안/README.md` 의 「가게 주인 v11」 소절에 있다.

## 잘 된 것

- **큰 그림을 줄인 뒤 `edit_image_pro_flash`(method=text)로 「깨끗한 도트로 다시 그려라」** 가 가장 잘 먹었다.
  얼굴·자세·옷이 그대로 남고 잡티만 정리된다. 한 장 5~6회, 30초 안팎.
- `edit_image_pro_flash`(method=reference)에 **바탕 = 손님 그림, 참고 = 줄인 주인 그림** 을 주면 손님 몸 비율·도트 굵기를 그대로 지킨 채 옷과 머리만 바뀐다.
- 64×80 · 72×88 · 80×100 같은 맞춤 캔버스(4의 배수)가 편집에서 그대로 통했다.
- 64×80 PNG 는 base64 가 3~5천 자라 `image_base64` 로 바로 넣을 수 있었다. 올릴 곳을 따로 찾지 않아도 된다.

## 막힌 것

- **`create_image_pro_flash` 는 캔버스를 키워도 캐릭터가 안 커진다.** 80×96 을 시켰는데 그림은 64×80 때와 같은 47×77 로 왔다. 「조금 큰 판」은 줄인 그림을 넣는 편집으로 돌아가야 했다.
- 화풍 그림(손님)을 줘도 머리 외곽선이 안 따라왔다 (머리가 선 없이 뽀글뽀글).
- 볼 다이아는 작은 크기에서 2×2 붉은 덩어리로 오거나(글 편집) 아예 안 온다(참고 편집). 결국 PIL 로 5픽셀을 찍었다.
- `wait_for_jobs` 는 계정 전체의 일을 본다. 다른 세션이 같이 돌리면 남의 일이 끝난 것도 깨운다. 내 job id 를 적어 두고 그것만 `get_image` 해야 한다.
- `get_image` 가 그림을 세션 폴더의 blob 파일로 떨어뜨린다. 이름이 임의라 받은 즉시 뜻 있는 이름으로 복사해 둬야 헷갈리지 않는다.

## 바라는 것

- 그림툴 문서에 「큰 그림 → 줄이기 → 글 편집으로 다시 그리기」 를 작은 크기 만들기의 기본 길로 적어 두면 좋겠다.
- 쓴 크레딧 : 7장 36회 (5회 여섯 장 + 6회 한 장).
