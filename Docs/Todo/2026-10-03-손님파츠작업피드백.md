# 손님 파츠 작업 피드백 — PixelLab 으로 겹 나누기 (2026-10-03)

## 결론

**「기본체 1장 + `inpaint_image` 에 내 마스크 + 기본체와 diff」 가 파츠 나누기에 통한다.**
inpaint 는 마스크 밖을 한 픽셀도 안 바꿔서, 달라진 칸만 떼면 그대로 겹이 된다. 64×80 한 장에 20 생성 · 30~60초다.
기본체 1 + 파츠 14 를 겹 46장(색 바꾼 것 포함)으로 만드는 데 PixelLab 383 생성(pixflux 3 + inpaint 19)을 썼다.

## 잘 된 것

| 무엇 | 어떻게 |
| --- | --- |
| 겹 자리 맞춤 | inpaint 결과와 기본체의 픽셀 차이가 마스크 밖에서 0 이었다. 자리 맞추는 손질이 필요 없다 |
| 그림을 URL 로 넘기기 | `image_url` 에 앞 판의 download URL 을 그대로 넣었다. base64 는 마스크(200자쯤)만 넣으면 된다 |
| 색 바꿀 파츠를 파랑으로 뽑기 | 글머리에 royal blue 를 넣으면 살색과 색상이 멀어 「머리·옷 칸」을 색상만으로 가를 수 있다 |
| 옷 색 단 | 옷은 파랑이 3~5색으로 나와 따로 줄일 필요가 거의 없었다. 머리는 9~15색이라 밝기 비율로 6단에 묶었다 |
| 표정 | 얼굴 칸만 마스크로 주면 눈 감은 웃음 · 눈물 시무룩이 한 번에 나왔다 |
| 한꺼번에 돌리기 | inpaint 10개까지 동시에 걸린다 |

## 막힌 것

| 무엇 | 어떻게 됐나 | 돌아간 길 |
| --- | --- | --- |
| 동시 작업 상한 | 계정 전체로 10개다. 다른 세션이 같이 쓰면 `rate limit exceeded (10/10 jobs)` 가 난다 | 끝난 뒤 다시 건다. `wait_for_jobs` 는 남의 작업도 같이 센다 |
| 네모 마스크 가장자리 | 머리 마스크에서 얼굴을 네모로 빼면 앞머리·단발 밑단이 그 선에서 일자로 잘린다 | 빼는 칸을 눈·입만으로 줄였다. 그래도 똑단발은 일자다 |
| 긴 머리와 옷 자리 나누기 | 머리와 윗옷 마스크를 안 겹치게 하면 머리가 어깨에서 끊기고 가는 줄만 남는다 | 어깨 위를 머리 마스크에 넣고, 겹에서는 어깨 아래를 파란 칸만 남겼다 |
| 기본체 윤곽을 깎음 | 파츠를 입히며 정수리 한 줄 · 어깨선 몇 칸을 투명으로 바꾼다. 겹을 얹으면 그 칸에서 몸이 삐져나온다 | 「모든 파츠가 가리거나 깎는 칸」을 몸에서 뺐다 (32칸). 한 파츠만 깎은 8칸은 남았다 |
| 눈을 더 크게 다시 그리기 | 얼굴 칸 inpaint 로 낸 눈은 흐릿한 갈색이라 기본체 눈보다 약했다 (2판 버림) | 기본 눈은 pixflux 기본체 것을 썼다 |
| 다시 그려진 흰 옷 조각 | 머리 마스크가 목·어깨에 닿으면 흰 옷 몇 칸을 새로 그린다. 다른 옷 위에서 흰 점이 된다 | 머리 겹의 턱 아래 흰 칸을 지웠다 |
| `search_knowledge` | Phaser 게임 만들기 지식만 나온다. 그림 도구 고르는 데는 쓸모가 없어 부르지 않았다 | 도구 설명을 직접 읽었다 |

## 바라는 것

- 마스크를 네모가 아니라 「이 색 칸만」으로 주는 길이 있으면 얼굴 빼기가 쉬워진다.
- 기본체 윤곽을 깎지 않는 옵션(불투명 칸은 지우지 않기)이 있으면 몸 손질이 필요 없다.
