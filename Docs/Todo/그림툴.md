# 할 일 : 그림 툴

> 담당 범위 : 2D 그래픽 (타일 · 스프라이트 · UI)
> 이 툴의 색인은 `Docs/Todo/진행상황.md`, 프로젝트 전체 색인은 스튜디오 저장소(Officina)의 진행 상황 문서에 있다
> 마지막 고침 : 2026-08-25

## 1. 툴 경계 — 셋으로 나눈다

| 툴 | 무엇 | 주력 | 상태 |
| --- | --- | --- | --- |
| **스프라이트 툴** | 캐릭터 + **프롭**(나무·바위·통) | 에셋 + AI | 설계·1차 구현 끝(2026-08-25) |
| **타일 툴** | 지형 타일 (바닥·벽·경계) | **코드** | 설계·1차 구현 끝(2026-08-25) |
| **UI 툴** | 게임에 들어가는 버튼·창·아이콘 | **코드(프레임 생성기) + 에셋(Kenney)** | 조사·설계·1차 구현 끝(2026-08-25) |

- **프롭은 배경이 아니라 스프라이트 쪽이다.** 한 장짜리 그림이라 캐릭터와 같은 문제다.
- **팔레트는 색을 바꾸지 모양을 못 바꾼다.** 그래서 지형 타일과 프롭이 갈린다.
- **UI 툴은 설명용 그림 툴(`Todo/설명용그림툴.md`)과 다른 물건이다.**
  3번은 기획·설계 때 **우리끼리 보는** 그림, UI 툴은 **게임에 실제로 들어가는** 그림.
  UI 는 그림보다 **9-slice, 폰트, 해상도 대응, 레이아웃**이 중요해서 팔레트·오토타일이 안 통한다.

## 2. 정해진 것

### 공통

| 항목 | 결정 | 근거 |
| --- | --- | --- |
| **툴의 정체** | 그림을 그려 주는 툴이 **아니다.** 규격 맞추기 → 앵커 뽑기 → 검수 → Unity 데이터 굽기 | `Design/2026-08-20-그림툴결정사항.md` |
| 툴 구조 | **툴 하나 + 프로필 설정 파일.** 툴을 쪼개지 않는다 | 〃 |
| 제공자 구조 | 인터페이스 하나, 뒤의 생성기를 갈아끼운다 (기본=코드 / 로컬 모델 / PixelLab) | `Research/2026-08-20-배경그림오픈소스대안조사.md` |
| PixelLab | **키트에는 필수 아님.** 키를 넣으면 켜지는 선택 제공자. 우리 프로젝트에선 씀(상업 이용 확인, Pro 결제됨) | 〃 |
| 검수 | **코드로 한다** (numpy / Pillow). VLM 안 씀 — 정확도 45.2% 근거 | `Design/2026-08-20-그림툴결정사항.md` |
| 캔버스 | 64×64 | 〃 |
| 라이선스 | CC0 / CC-BY / OGA-BY 3.0. CC-BY-SA·GPL 배제 | 〃 |
| 그림체 | **기반 에셋(LPC) 그림체를 따라간다.** 슬라임도 여기 맞춘다 |
| 팔레트 교체 | 런타임 LUT 셰이더 + 굽기 스크립트. **직접 구현** | `Research/2026-08-20-배경툴후보검증.md` |

> ⚠️ **갱신됨** : 위 결정 문서의 "시점 = 탑다운 / 방향 = 4방향" 줄은
> **축 3개(투영·방향 수·이동)로 바뀌었다.** 스튜디오 저장소의 프로젝트 개요 문서가 최신이다.
> "방향 수 4 vs 3" 미정 항목도 축 설정으로 흡수됐다.

### 스프라이트 툴

| 항목 | 결정 |
| --- | --- |
| 캐릭터 종류 | 사람 + 비인간(슬라임). **부착점 목록이 서로 다르다** |
| 부착 방식 | **rig 로 가른다.** 사람 = LPC 층 겹치기, 슬라임 = 앵커 부착 |
| 앵커 데이터 | 위치 + **앞뒤 순서**. 순서도 프레임마다 바뀐다 |
| Unity 부착 | 런타임 부착 (미리 굽기는 조합이 터진다) |
| 코스튬 40종 | **실루엣 M 8종 × 색 K 5가지. 손그림 0장.** M 은 LPC 기성품에서 |
| 슬라임 | 몸 색 8 × 부착물 5 = 40종, 손그림 20장 |

### 타일 툴

| 항목 | 결정 |
| --- | --- |
| 3단 구조 | ① 타일 그림 ② 이어붙이기 ③ 배치. **②③은 순수 코드** |
| 부풀리기 | **템플릿 6장 → 47장 blob.** 직접 구현 (`blobator` MIT·C# 참고) |
| 기반 에셋 | **Kenney (CC0)** 를 템플릿에 기본 제공 |
| 갖다 쓸 것 | **DeBroglie**(MIT, 배치) · **LDtkToUnity**(MIT, 가져오기) **둘뿐** |
| 쓰면 안 됨 | WangTile · TileableTextureSynthesis (**라이선스 없음**) |
| 참고만 | TilePipe · itsjavi/autotiler (MIT지만 2~3년째 멈춤) |
| 뒤로 뺌 | 텍스처 합성 — 후보가 라이선스 없거나 보관 처리됨 |
| 아이소 / 셰이더 포팅 | **비용 낮음.** 47-blob 은 위상이 정사각과 같고, 깊이 정렬은 Unity 기본 기능 |
