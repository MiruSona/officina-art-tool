# 겹 나누기 경험 모음과 검사 요청 (2026-10-07)

게임 저장소에서 그림을 겹(레이어)으로 나눠 일한 것을 한데 모았다. 2026-09-20 부터 10-07 까지 사례 열 개다.
**대부분 이 툴을 거치지 않았다** — PIL 스크립트를 그때그때 짜서 나누고, 메우고, 견줌판을 구웠다.
그래서 「다음엔 툴이 해 줬으면」 하는 검사를 끝에 적는다.

> 반영 : 아직 안 함.

## 결론

- 겹 나누기는 **세 길**로 했다. ① 처음부터 겹마다 따로 그리기 ② 한 장을 색·자리로 가르기 ③ 기본체에 inpaint 를 걸고 달라진 칸만 떼기.
  자리가 저절로 맞는 것은 ①·③ 이다. ② 는 색이 겹치면 갈리지 않는다.
- **흰(회색) 겹 + 코드가 색 곱하기** 는 매번 잘 됐다. 한 벌 그림을 여러 색이 같이 쓴다.
- 손이 가장 많이 간 곳은 **겹을 떼고 남은 구멍 메우기**다. 이웃 평균으로 메우면 번져 보이고 색 수가 늘었다. 옆 칸을 그대로 옮겨 붙이니(결 복사) 풀렸다.
- 지금 `layers check` 는 「합친 결과 = 원본」과 「아래 겹 삐짐」을 본다. **캔버스·기준점 맞춤, 마스크 틈, 안쪽 구멍, 새 색 수, 물들인 미리보기** 는 아직 없다.

## 사례

수치는 사례 폴더의 README · 스크립트 머리 주석 · 이번에 다시 잰 값만 적었다. 다시 못 잰 것은 「못 잼」이라 적었다.

### 1. 주인공 캐릭터 네 겹 (09-20)

- **나눔** : 몸(64) · 볼(11) · 표정(64) · 장식(64) 네 겹. 겹마다 따로 그리고 프리팹 기준점에 끼웠다.
- **색** : 몸만 흰색으로 그리고 코드가 종 색을 곱한다. 12종이 그림 한 벌을 같이 쓴다.
- **잘 된 것** : 표정 · 장식을 코드로 갈아 끼운다.
- **막힌 것** : 한 장으로 나온 그림을 손으로 잘라 냈다 (이 폴더 `2026-09-20-캐릭터레이어작업피드백.md`).
- **규칙** : 바뀌는 것(표정 · 장식 · 종 색)마다 겹 하나. 색이 바뀌는 겹은 흰색으로 그린다.

### 2. 사람 캐릭터 한 장을 색면과 높이로 가르기 (09-22)

- **나눔** : 깨끗한 판 한 장을 **색면 + y 높이**로 갈라 몸 · 머리카락 · 옷 · 표정 네 겹.
- **잘 된 것** : 네 겹을 다시 쌓으면 원본과 **0px 차이**.
- **색** : 겹을 팔레트 교체로 구워 16장(몸 1 · 머리 2모양×4색 · 옷 4색 · 표정 3). 되돌림 검사에서 자리다름(알파) 0.
- **막힌 것** : 밝기를 계산해 새 색을 고르면 원본보다 어두워졌다. 색 표 값을 1:1 로 꽂아 풀었다.
- **규칙** : 색만 바꾸는 겹은 계산 말고 색 표 1:1. 구운 뒤 「쌓기 = 원본」 견줌을 꼭 한다.

### 3. 기본체 + inpaint 로 떼기 (10-03)

- **나눔** : 머리 없는 기본체 한 장에 inpaint 를 내 마스크로 걸어 머리 · 옷 · 표정만 입힌다. 기본체와 **달라진 칸만** 떼면 같은 캔버스의 겹이 된다. 64×80 겹 46장.
- **잘 된 것** : inpaint 는 마스크 밖을 안 바꾼다. 그래서 자리 맞춤이 필요 없다.
- **막힌 것** :
  - 얼굴을 네모로 뺀 머리 마스크는 앞머리가 그 선에서 일자로 잘렸다.
  - inpaint 가 기본체 윤곽 몇 칸을 깎았다 (지금 `layers diff --carve` 가 이 일을 맡는다).
  - 「바뀐 것만」 출력이 바뀐 점이 아니라 마스크 칸 전체를 준다.
- **규칙** : 마스크 경계는 그림 결을 따라 그린다. 네모로 자르지 않는다.

### 4. 도는 움직임을 먼 두 색으로 뽑고 가르기 (10-05)

- **나눔** : 밑그림에서 가를 덩이를 **분홍 · 민트처럼 먼 두 색**으로 시켰다. 움직임을 뽑은 뒤 색으로 갈라 겹마다 다시 칠했다.
- **막힌 것** : 빈틈이 회색 `#80807F` 로 채워져 나왔다 → 투명으로 지웠다. 첫 두 장은 색이 옅어 버렸다.
- **규칙** : 나중에 색으로 가를 거면 **뽑을 때부터 먼 색**으로 시킨다.

### 5. 작은 아이콘 물들임 두 화법 (09-21)

- **나눔** : 24px 아이콘을 「몸 전체 물들임」과 「흰 몸 + 위에 얹는 것」 두 벌로 그려 견줬다.
- **결과** : 판정 전이라 어느 쪽이 나았는지는 못 적는다.

### 6. 뚜껑 달린 기계를 몸통 · 뚜껑 두 겹으로 (10-07)

- **나눔** : 뚜껑 열린 한 장을 몸통 · 들린 뚜껑 두 겹으로 갈랐다. 같은 캔버스(180×199). 몸통 → 김 → 뚜껑 차례로 쌓으면 원본과 같다.
- **막힌 것** : 뚜껑에 가렸던 몸통 테두리가 **비어 있고**, 뚜껑 아래 끝 몇 px 이 몸통 쪽에 남았다. 뚜껑을 얹으면 안 보여서 그냥 뒀다.
- **규칙** : 가려졌던 칸이 빈 것은 「위 겹이 덮나」만 확인되면 된다. 덮는지 숫자로 보고 싶다.

### 7. 투명 용기 내용물 겹 — 첫 시도 (10-07)

- **나눔** : 105×176 네 장을 **용기 몸통 겹 + 내용물 겹**으로. 내용물은 밝기만 남긴 회색(가장 밝은 칸 255), 그 밖은 투명. 몸통은 내용물 자리를 빈 유리 색으로 메웠다.
- **색** : 물들임 = 곱하기 (칸 색 = 회색 × 물들임 색 / 255). 견줌판 12칸으로 재료 색마다 확인.
- **막힌 것** : **흰 반사와 흰 내용물이 색으로 안 갈렸다.** 소용돌이 · 떠 있는 덩어리가 내용물 겹에서 빠져 물들여도 흰색으로 남았다.
- **규칙** : 색으로 가를 거면 갈라야 할 두 덩이의 색이 겹치는지 먼저 본다.

### 8. 투명 용기 내용물 겹 — 다시 (10-07)

- **나눔** : 몸통은 한 장(사례 7 의 몸통)을 모든 장이 같이 쓴다. 내용물만 새로 뽑아 **회색 겹 9장** + **층 마스크 30장**(장 0~5 × 2층 · 3층). 재료를 2~3개 넣으면 아래부터 층마다 다른 색을 곱한다.
- **층 경계** : 열마다 윗면 y 와 바닥 y 를 찾아 n 등분. 윗면 꼴을 따라 경계가 울퉁불퉁해진다.
- **막힌 것 1 — 구멍** : 유리 반사 · 축 · 받침처럼 내용물 색이 아닌 칸이 겹에서 빠져 **투명 구멍**이 생겼다. 그 구멍으로 몸통의 밝은 유리가 비쳐 세로줄 · 가로줄 · 회색 조각으로 보였다.
- **막힌 것 2 — 메움** : 구멍을 **이웃 평균**으로 메웠더니 번져 보였다. **결 복사**(같은 행에서 구멍 폭만큼 옆으로 민 자리, 또는 5×5 이웃의 아는 칸 하나를 그대로 옮김. 새 색 안 만듦)로 바꿨다.
- **몸통 손질** : 통 안 가운데 축(x41..55, y33..57)을 지우고, 같은 행의 맨 유리 칸에서 하나씩 골라 붙였다. 유리 팔레트 5색만 쓴다.
- **잰 값 (이번에 다시 잼)** :

| 무엇 | 값 |
| --- | --- |
| 내용물 겹 색 수 — 손질 전 | 장마다 21~23색 |
| 내용물 겹 색 수 — 평균 메움 | 35~123색 (본줄 세션이 잰 값. 그 판 파일이 남지 않아 **못 다시 잼**) |
| 내용물 겹 색 수 — 결 복사 | 장마다 19~23색 |
| 층 마스크 합집합 vs 회색 겹 (12묶음) | 틈 0 · 겹침 0 · 밖 0 |
| 캔버스 | 모든 겹 105×176 |

- **규칙** : 구멍은 평균 말고 **결 복사**로 메운다. 메운 뒤 색 수가 원본보다 늘었으면 번진 것이다.

### 9. 받침 그릇 · 도구 · 재료 덩어리 세 겹 (10-07)

- **나눔** : 받침 그릇 / 도구 / 재료 덩어리를 **같은 캔버스(440×560) · 같은 기준점(바닥 가운데 (220,560))** 에 따로 그렸다. 그대로 겹치면 한 장면이다.
- **겹 순서** : 받침 그릇 < 도구 < 재료 덩어리. 모든 장에서 고정한다. 도구가 덩어리에 묻히는 장은 덩어리 겹이 도구 머리를 덮어서 표현한다.
- **장 맞춤** : 장 번호가 같으면 같은 순간. 단계마다 8장, 넘어감마다 4장. 세 겹이 장 수가 같다.
- **색** : 덩어리는 흰색 한 가지로 그리고 코드가 물들인다.
- **막힌 것** : 이전 판은 한 장 그림 위에 덩어리 움직임만 따로 얹어서 따로 노는 것처럼 보였다. 세 겹으로 다시 그려 풀었다.
- **규칙** : 같이 움직이는 겹은 **캔버스 · 기준점 · 장 수 · 순서**를 처음에 표로 박고 그린다.

### 10. 화면 밖에서 잡는 도구 (10-07)

- 도구 자루가 화면 밖으로 나가는 장은 **캔버스 끝을 프레임 끝에 맞춰** 그려야 자루가 허공에서 잘리지 않는다.
