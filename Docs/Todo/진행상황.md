- **TMP 폰트는 `Dynamic` 으로 만들어 글자를 다 넣은 뒤 `Static` 으로 잠근다.** 처음부터 `Static` 이면
  `TryAddCharacters` 가 조용히 실패해 빈 폰트가 구워진다 (`mem show 20260825-2674917e`).

  플레이어 빌드가 컴파일 오류로 깨진다 (`mem show 20260825-25877857`).
- 시험 돌리는 법 (`README.md` 「설치」 참고) — 스튜디오에서는 `<이 툴>/.venv/Scripts/python -m pytest <이 툴> -q`,
  이 툴 저장소 단독에서는 `.venv/Scripts/python -m pytest -q`
- **환경변수 `PYTHONIOENCODING=utf-8` 이 걸린 셸(Claude Code 세션 등)에서는 `test_module_entry_point` 하나가 깨진다.**
  자식은 UTF-8 로 찍고 시험은 cp949 로 읽기 때문이다. `$env:PYTHONUTF8='1'` 을 걸고 돌리면 통과한다 (10-03 확인)
