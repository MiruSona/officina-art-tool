## 주의

- **east 그림은 규격을 맞춘(fit_frame) west 결과를 뒤집어 만든다.** 원본을 먼저 뒤집으면 가운데 맞추기가
  다시 걸려 앵커 공식과 1~2px 어긋난다 (`mem show 20260825-f6df9e26`).
- **TMP 폰트는 `Dynamic` 으로 만들어 글자를 다 넣은 뒤 `Static` 으로 잠근다.** 처음부터 `Static` 이면
  `TryAddCharacters` 가 조용히 실패해 빈 폰트가 구워진다 (`mem show 20260825-2674917e`).
- **에디터 전용 C# 은 `Editor` 폴더 안에 둔다.** 밖에 두면 `UnityEditor` 네임스페이스 때문에
  플레이어 빌드가 컴파일 오류로 깨진다 (`mem show 20260825-25877857`).
- 시험 돌리는 법 (`README.md` 「설치」 참고) — 스튜디오에서는 `ArtTool/.venv/Scripts/python -m pytest ArtTool -q`,
  ArtTool 저장소 단독에서는 `.venv/Scripts/python -m pytest -q`

결정·교훈·공수·할 일은 mem 에 있다. `mem search arttool` 로 찾는다.

## 2026-09-21 코드 리뷰 수정 (위 반영분에 대한 리뷰 11건)

위 낱장 길 · `setup.ps1` 변경을 코드 리뷰로 다시 훑어 11건을 고쳤다 (시험 401 → 422).
가장 컸던 둘은 **제자리 `--fit` 이 그림을 안 쓰던 것**과 **`frames.json` 없는 폴더가 조용히 ok 가 되던 것**이다.

| 무엇 | 자리 |
| --- | --- |
| `--fit` 을 제자리(`--in`==`--out`)에 써도 맞춘 그림을 덮어쓴다. 전에는 `icons.json` 만 16 이고 파일은 20×20 이었다 | `ui/icons.py` `gather` |
| `frames.json` 이 없어 낱장 모드로 내려갈 때 stderr 에 「낱장 모드로 본다 — 건너뛴 검사 : …」를 찍는다 | `check.py` `run` |
| 보고의 `skipped` 가 **실제로 건너뛴 규칙 전부**다 (`baseline` · `bbox_drift` + `--no-ramps` 의 `ramp_colors`) | `check.py` `_report` · `run_loose` |
| 낱장 보고(`"mode": "loose"`)로 프레임을 구우면 `--force` 없이 거절한다 | `bake.py` `gate` |
| 프로필의 `ramps_file: ""` 는 **「설정상 없는 검사」**라 `skipped` 에 안 넣는다. 최소 프로필 사용자가 `bake` 에서 막히면 안 된다 | `check.py` · `README.md` |
| 조용히 무시되던 인자 조합을 거절한다 — 폴더 + `--cell`, 시트 + `--fit`, `--fit` 0·음수 | `cli.py` `_ui_icons` |
| 크기가 섞인 낱장 폴더면 `cell` 이 `null` 이고 `sizes` 에 나온 크기를 다 적는다 | `ui/icons.py` `gather` |
| 속이 텅 빈 PNG 는 `cut()` 과 같게 건너뛰고 `empty_cells` 로 센다 (`--fit` 유무와 무관) | 같은 곳 |
| `check` 입구에서 없는 경로 · PNG 아닌 파일을 각각의 말로 거절한다 | `check.py` `check_source` |
| `glob("*.png")` 대신 확장자를 대소문자 없이 보는 `png_files()`. 하위 폴더는 안 본다 | `check.py` · `ui/icons.py` |
| `setup.ps1` — 실행 정책이 `Restricted` 여도 되게 README 를 `-ExecutionPolicy Bypass` 로. 파이썬 판을 실제로 재고(`>=3.11`), `python` 이 없으면 `py -3` 로 한 번 더 찾고, 끝까지 되면 `.venv\.setup-stamp` 에 시각을 적는다 | `setup.ps1` · `README.md` |

**확인한 것** : `pytest -q` 422개 통과, 위 11건을 실제 CLI 로 한 번씩 손으로 돌려 봄,
`setup.ps1` 을 `-ExecutionPolicy Bypass` 로 돌려 종료 0 과 `.setup-stamp` 생성 확인.
