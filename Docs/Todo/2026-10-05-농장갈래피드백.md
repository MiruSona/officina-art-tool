# 농장 갈래 피드백 (2026-10-05)

> 화풍 통일 C 갈래(주인공 캐릭터 몸 선 시안 · 몸 색 합치기 · 풀 장식 색 옮김 · 합성 결과 판 색 합치기)에서 이 툴을 쓴 느낌이다.
> 쓴 명령 : `check --profile` · `layers check`. 그림 손질은 모두 PIL 로 했다.

## 잘 된 것

- `check` 의 `near_colors` 보고가 **합칠 색 짝을 칸 수와 함께** 알려 줘서 무엇을 합칠지 바로 보였다.
- `layers check` 가 낱장 겹을 폴더로 세우기만 하면 바로 돌았다.
- 기준선 대 고친 뒤를 보고 JSON 둘로 견주기 쉬웠다.

## 막힌 것 · 없어서 PIL 로 한 것

| 무엇 | 지금 | 바라는 것 |
| --- | --- | --- |
| 비슷한 색 합치기 | `near_colors` 가 짝은 알려 주지만 **합쳐 주는 명령이 없다** | `<툴> merge-colors --max-delta N --limit M` — 칸 수 많은 쪽으로 합치고 알파는 그대로. 「정한 색 목록으로만 보내기」(`--to 팔레트`) 도 |
| 색 옮김 (색상 · 밝기 · 채도) | `tint` 는 곱하기뿐 | `<툴> shift --hue -10 --light +0.03 --sat 2.4 --pick <색 목록>` — 고른 색만 일대일로 |
| 선 색만 바꾸기 | `reline` 은 선을 다시 찾는다 | 「이 색 → 저 색」 한 줄 바꾸기 (`recolor` 가 겹 묶음 없이 낱장에도 되면 된다) |
| 배경 위에 놓은 비교판 | `sheet --bg` 는 체크무늬 · 단색뿐 | `--bg <타일 PNG>` — 잔디 타일 위에 놓고 지금 / 고친 뒤를 나란히 |
| 알파 그대로인지 확인 | 직접 스크립트 | `<툴> diff --alpha-only A B` (다른 칸 수 · 종료 코드) |

## 헷갈린 것

- 보고 JSON 의 실패 까닭은 `failed` · `rules` 칸에 있는데 처음엔 `warnings` 만 봐서 놓쳤다. 명령안내에 「실패는 `failed`, 경고는 `warnings`」 한 줄이 있으면 좋겠다.
- 색을 합친 뒤 생기는 **홀로 남은 1 ~ 2칸 점**은 `isolated` 가 못 잡았다 (비율 한도 아래). 합치기 명령이 생기면 점 메우기까지 같이 해 주면 좋다.
