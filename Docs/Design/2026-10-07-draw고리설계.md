# draw 고리 설계 — 그리고 → 보고 → 고치는 고리를 `arttool.draw` 위에 얹기 (2026-10-07)

**에이전트가 적는 것을 「좌표」에서 「문자 격자」로, 돌려받는 것을 「PNG」에서 「PNG + 글(격자 · 좌표 박힌 결함)」로 바꾸고, 2~3바퀴를 스킬 규칙으로 못 박는다. 새 의존성 · 외부 바이너리 없음. 값어치는 같은 캐릭터 3장 vs 3장 실측으로 잰다.**

앞 문서 : `Docs/Research/2026-10-07-AI용그림툴조사.md` 4~6절(밑그림 · 분류 · 판정). 기존 설계 : `Docs/Design/2026-10-04-ArtTool개선설계.md` 6-5 · 10-4 · 17-4.

## 왜 하나

- 지금 PIL 길은 에이전트가 좌표를 글로 적어 찍고, 결과는 7단계에서 **사람 눈**으로만 본다. 아이콘 · 타일은 되지만 캐릭터는 무너진다.
- `report()` · `check` 는 겹 · 파일 단위 몫만 준다(`isolated` 는 몫 + 앞 50칸). 에이전트가 「어느 칸을 고쳐야 하나」를 못 읽는다.
- 2025~26 에이전트용 도트 툴 5개 이상이 「격자 되읽기 + 좌표 린트 + 대칭/클립 + 변경 영역 미리보기」로 수렴했다(조사 1절).

## 범위

| 안 | 밖 |
| --- | --- |
| ① 문자 격자 읽기/쓰기 ② 좌표 박힌 린트 ③ symmetry · clip ④ 변경 영역 미리보기 ⑤ 스킬 절차 ⑥ 실측 설계 | 리그 · SVG trace · 오토타일(dotloom 참고만) · 마스크→색칠 생성기(조사 ⑥, 소품 대량 생산 때) · PixelLab 대체 · 로컬 LLM 실측 · 기존 `report()` 경고 꼴 바꾸기 |

## 1. 고리 한눈에

| 단계 | 하는 것 | 쓰는 것 |
| --- | --- | --- |
| 계획 | 크기 · 팔레트 · 실루엣 정하기 | 지금 그대로 (`template render` · `Canvas`) |
| 그리기 | 큰 덩어리는 도형, 세부(눈 · 손 · 장식)는 격자 글 | `Layer.*` 도형 · `paste_grid` · `symmetry` · `clip` |
| 글로 읽기 | 한 글자 = 한 픽셀 | `to_grid(box=…)` |
| 린트 | 좌표 박힌 결함 + 수치 | `lint()` |
| 그림 보기 | 바뀐 영역만 확대 PNG 를 Read | `preview_changed()` |
| 비판 | 체크리스트 5항목을 글로 답한다 | 스킬 `고리-그리기.md` |
| 고치기 | 바뀐 글자만 다시 `paste_grid`, 바뀐 칸 수 확인 | `changed()` · `mark()` |
| 멈춤 | 린트 0 + 체크리스트 전부 예, 또는 3바퀴 | 스킬 규칙 |

## 2. 문자 격자

### 2-1. 문법 (pxart `.px` 꼴을 따른다 — 코드는 안 베낀다)

```
# 범례 : 한 글자 → 색. '.' 은 늘 투명(안 적어도 된다)
k #2A2238
s #F6D0B0
w #FFFFFF

   01234567
 0 ssssssss
 1 sskkskks
 2 skwkskwk
 3 skkkskkk
 4 ssssssss
```

| 규칙 | 뜻 |
| --- | --- |
| 범례 줄 | `글자 #RRGGBB`. 글자는 `.` 과 공백 빼고 한 글자. 자동 배정 순서 `a-z` → `A-Z` → `0-9` (최대 62색 — 캐릭터 색 한도 안) |
| 격자 줄 | 범례 글자만, 모든 줄 너비 같음. 빈 줄 하나로 범례와 격자를 가른다 |
| 눈금(`rulers=True`) | 맨 위 x 눈금 한 줄 + 줄마다 `yy ` 머리. **읽기용**. `from_grid` 는 `^\s*\d+\s` 머리와 눈금 줄을 떼고 읽는다 |
| `#` 줄 | 주석 |
| 글자표 고정 | `Canvas.legend` 가 세션 동안 같은 색 → 같은 글자를 지킨다(되읽고 되쓸 때 글자가 바뀌면 에이전트가 틀린다). `legend=` 인자로 직접 줄 수도 있다 |
| 창(box) | `(x0, y0, x1, y1)` 끝 뺌, `shapes` 좌표 약속 그대로. 눈금은 캔버스 절대 좌표 |
| 64px 한도 | 창 없이 `to_grid` 를 부를 때 너비 · 높이 어느 쪽이든 64 를 넘으면 **거절**하고 가이드 상자 이름(`head` · `torso` …)을 안내한다. 축소는 안 한다 |

### 2-2. 모듈 · 함수

| 이름 | 입력 | 출력 | 파일 |
| --- | --- | --- | --- |
| `Legend` | `dict[str, RGB]` 또는 빈 것 | 색 ↔ 글자 양방향 · `assign(rgb)` · `text()` 범례 줄 | `draw/grid.py` (새) |
| `to_text(arr, legend, box=None, rulers=False)` | RGBA 배열 | 격자 글(범례 + 줄) | `draw/grid.py` |
| `parse(text)` | 격자 글 | `(legend, rows, (w, h))` · 너비 불일치 · 범례 밖 글자는 `ArtToolError` 에 줄 번호 | `draw/grid.py` |
| `Layer.to_grid(box=None, rulers=False, legend=None)` | | 격자 글. 투명 `.` | `draw/canvas.py` |
| `Layer.paste_grid(text, at=(0, 0), mode="over")` | 격자 글(범례 포함 또는 `Canvas.legend` 사용) | 자기 겹(이어 부르기). `over` : `.` 은 건드리지 않음 · `replace` : `.` 은 지움. `paint`/`erase` 를 통해 찍어 symmetry · clip · dirty 가 같이 든다 | `draw/canvas.py` |
| `Canvas.to_grid(layer=None, box=None, rulers=False)` | | `layer` 없으면 합친 그림. `Canvas.legend` 공유 | `draw/canvas.py` |
| `Canvas.paste_grid(layer, text, at, mode)` | | `self[layer].paste_grid` 와 같음 + 보고용 | `draw/canvas.py` |
| `Canvas.legend` | 속성 | `Legend`. 팔레트가 있으면 램프 순서대로 미리 글자를 준다 | `draw/canvas.py` |

### 2-3. CLI

| 명령 | 하는 것 |
| --- | --- |
| `arttool grid show --in <겹 묶음 폴더 \| PNG> [--item idle] [--layer body] [--box x,y,w,h] [--rulers] [--legend l.json]` | 격자 글을 찍는다(파일 안 씀). 64 넘으면 `--box` 요구(종료 2) |
| `arttool grid apply --in <폴더 \| PNG> --grid patch.px --layer face --at x,y [--mode over\|replace] --out <새 폴더 \| PNG> [--report r.json]` | 패치를 덧그려 **새 자리**에 쓴다(원본 보호 17절). 보고에 `pixels_written` · `pixels_clipped` · `bbox` |

`--dry-run` 은 `apply` 가 받는다(한두 장 쓰는 명령 묶음).

## 3. 좌표 박힌 린트

- 새 모듈 `draw/lint.py`, 공개 이름 `lint(arr_or_canvas, *, ramps=None, light="top_left", outline_mode=None, rules=None, waive=())`.
- 규칙 이름은 모두 **`lint.` 머리**를 붙여 `report()`(`palette` · `alpha` · `empty` …) · `check`(`isolated` · `outline` …) 와 겹치지 않는다.
- 보고 꼴 : `{"status": "ok|warn", "issues": [{"rule", "layer", "x", "y", "color", "detail"}], "counts": {rule: n}, "metrics": {...}}` + `lines()` 로 한 줄 글(`lint.orphan hair (12,7) #6A3E2A 8이웃에 같은 색 없음`).
- `status` 는 켠 규칙 중 하나라도 걸리면 `warn`. `report()` 와 `check` 의 `status` 는 **건드리지 않는다.**

| 이름 | 뜻 | 좌표 꼴 | 기본 |
| --- | --- | --- | --- |
| `lint.orphan` | 불투명 칸인데 8이웃에 같은 색이 없다(`checks/pixels.py::measure_isolated` 와 같은 정의, 몫 문턱 없이 전부) | 칸 (x, y) | 켬 |
| `lint.hole` | 투명 칸 하나가 4방향 모두 불투명 | 칸 | 켬 |
| `lint.stray_color` | 팔레트 밖 색 칸(팔레트 있을 때) | 칸 + 색 | 켬 |
| `lint.alpha_px` | 알파 0 · 255 가 아닌 칸 | 칸 | 켬 |
| `lint.outline_gap` | 합친 실루엣 가장자리 칸(`outline.edge`) 중 선이 아닌 칸 — `black`/`solid` 는 선 색이 아닌 칸, `selout` 계열은 안쪽 이웃보다 밝기가 어둡지 않은 칸 | 칸 | 외곽선 방식이 `none` · unset 이 아니면 켬 |
| `lint.double` | 1px 선(불투명 이웃 ≤ 2) 위 같은 색 2×2 뭉침(계단 리듬 깨짐) | 2×2 왼쪽 위 칸 | 끔 |
| `lint.asym` | 좌우 거울과 다른 칸 | 칸 (왼쪽만) | symmetry 켠 겹만 켬 |
| `lint.light_mismatch` | `metrics.light_guess` 가 `Canvas.light` 와 다름 | 없음(수치) | 끔 |
| 수치 `metrics.symmetry` | 거울과 같은 불투명 칸 ÷ 불투명 칸 (0~1) | — | 늘 |
| 수치 `metrics.center` | 불투명 칸 질량 중심 `[x, y]` + bbox 중심과의 차 | — | 늘 |
| 수치 `metrics.bbox` | `[x0, y0, x1, y1]` | — | 늘 |
| 수치 `metrics.light_guess` | 밝은 칸(램프 위 절반) 무게중심이 어두운 칸보다 어느 쪽인가 → `top_left` · `top` · `top_right` · `unknown` | — | 늘 |

- `waive=[(x, y), …]` 로 눈 흰 점처럼 **일부러 둔 칸**을 뺀다. 스킬 절차에서 「남기는 칸」을 적고 넘긴다.
- `Canvas.lint(**kw)` 는 겹마다 돌려 `layer` 를 채우고, `outline_gap` · 수치는 합친 그림으로 한 번 잰다.
- CLI : `arttool lint --in <폴더 \| PNG> [--template t.json] [--rules a,b] [--report r.json]` — 파일 안 씀, 걸려도 종료 0(경고 성격). `check` 에 합치지 않는다(이유 : 10절).

## 4. symmetry · clip

| 이름 | 입력 | 하는 것 | 파일 |
| --- | --- | --- | --- |
| `Layer.set_symmetry(axis)` | `"x"` · `None` | 켜 두면 `paint` · `erase` 마스크에 `mask[:, ::-1]` 을 합친다 — 반쪽만 그리면 거울. 홀수 너비 가운데 줄은 그대로 | `draw/canvas.py` |
| `Layer.set_clip(mask)` | 불리언 마스크 · `None` | 켜 두면 `paint` 마스크를 `& clip` 한다(실루엣 밖엔 안 찍힘). `erase` 는 안 막는다 | `draw/canvas.py` |
| `Layer.last` | 속성 | 마지막 칠하기의 `{"written": n, "clipped": n}` | `draw/canvas.py` |
| `Canvas.set_symmetry(axis, layers=None)` · `Canvas.set_clip(mask, layers=None)` | | 여러 겹에 한 번에 | `draw/canvas.py` |

- **`mirror()` 와의 관계** : `mirror()` 는 「지금 왼쪽을 오른쪽에 한 번 복사」, `set_symmetry` 는 「앞으로 찍는 것마다 거울」. 둘 다 둔다. 이미 그린 뒤 켜면 과거는 안 바뀐다 — 과거까지 맞추려면 `mirror()` 를 한 번 부른다.
- `outline()` 은 `Layer.arr` 에 직접 쓰므로 symmetry · clip 을 **안 탄다**(실루엣이 대칭이면 결과도 대칭). `where="outside"` 가 clip 밖으로 1칸 자라는 것은 지금과 같다 — 고리 절차에서 외곽선은 맨 마지막에 한 번만.
- `fill(x, y)` 은 flood 마스크가 clip 에 걸려 잘린다(원하는 동작).

## 5. 편집 뒤 변경 영역 미리보기

| 이름 | 하는 것 | 파일 |
| --- | --- | --- |
| `Layer.dirty` | 마지막 `mark()` 이후 바뀐 칸 마스크. `paint` · `erase` · `paste_grid` 가 켠다(`outline` 도 직접 켠다) | `draw/canvas.py` |
| `Canvas.mark()` | 바퀴 시작 — 모든 겹 `dirty` 를 비우고 지금 그림을 `_before` 로 복사 | `draw/canvas.py` |
| `Canvas.changed()` | `{"count": n, "bbox": [x0, y0, x1, y1], "layers": {name: n}}` (실제로 값이 달라진 칸만 센다 — 같은 색을 다시 칠한 칸은 안 센다) | `draw/canvas.py` |
| `Canvas.preview_changed(path, scale=8, pad=2)` | bbox 를 pad 만큼 넓혀 잘라 scale 배 PNG. 바뀐 칸 둘레에 1px 자홍 테를 두른다(pxart diff 의 자홍) | `draw/canvas.py` |
| `Canvas.diff_grid()` | bbox 창의 격자 글. 안 바뀐 칸은 `·`(가운뎃점), 바뀐 칸만 글자 | `draw/grid.py` 의 `diff_text(before, after, legend)` |

`preview_changed` 경로는 `preview` 와 같이 겹 묶음 폴더 안이면 거절한다.

## 6. 스킬 절차 (`arttool-usage/고리-그리기.md`, SKILL.md 에 한 줄)

| 쓴다 | 안 쓴다 (공식으로 충분) |
| --- | --- |
| 캐릭터(`char_small` · `char_blob` · `char_parts`) · 얼굴 있는 소품 · 세부가 있는 아이콘(`prop_small`) | 타일(`tile_base`) · 이펙트(`fx_*`) · 램프 · `ui9_panel` · 움직임 가이드 |

**한 바퀴**

1. `c.mark()` → 그린다(도형 + `paste_grid`, 캐릭터는 `set_symmetry("x")` 로 반쪽만, 겹마다 `set_clip(템플릿 마스크)`).
2. 글로 읽는다 : `c.lint().lines()` 와 `c.to_grid(box=g.box("head"), rulers=True)` 처럼 **창 단위**로.
3. 그림으로 본다 : `c.preview_changed("work/changed.png")` 와 `c.preview(..., scale=8)` 을 **Read 로 연다**(읽기 채널은 글 + 그림 둘).
4. 체크리스트를 글로 답한다 — ① 실루엣이 한 색으로 읽히나 ② 눈 · 입 자리가 가이드 줄에 있나 ③ 램프 밖 색 0 ④ 외곽선 끊김 0 ⑤ 빛이 `c.light` 쪽인가.
5. 고친다 : 바뀐 글자만 `paste_grid` → `c.changed()["count"]` 로 「고친 칸 수」가 생각과 같은지 본다.

**멈춤** : 켠 린트 0 **그리고** 체크리스트 5개 다 예 → 끝. 아니면 다음 바퀴. **3바퀴**가 끝나면 멈추고 남은 결함을 보고에 적는다(무한 고리 금지). 바퀴마다 `preview_changed` PNG 를 `work/loop_N.png` 로 남긴다.

**끝낸 뒤** 지금 절차 7~9(`layers check` → `export` → `check` → `sheet`)는 그대로.

## 7. 실측 설계

| 항목 | 내용 |
| --- | --- |
| 과제 | 같은 글귀 한 줄(예 : 「32×32 sd, 갈색 단발, 빨간 윗옷, 왼쪽 위 빛」) · `char_small` · 같은 팔레트 |
| A 지금 방식 | `draw_char_small.py` 꼴 — 도형 + 좌표, `report` · `sheet` 한 번, 고치기 없음. 3장 |
| B 고리 방식 | 6절 절차, 최대 3바퀴. 3장 |
| 잰다 | ① `lint` 결함 수(최종) ② `check` 경고 수 ③ 사람 점수 — 사용자가 **어느 쪽인지 모르게** 6장을 섞어 읽힘 · 귀여움 · 깔끔 1~5 ④ 턴 수 · 벽시계(`effort mark`) ⑤ 토큰(세션 `/cost` 또는 EffortTool 기록 — 토큰 칸이 없으면 턴 수로 대신) |
| 통과선(추천) | B 사람 점수 평균 ≥ A + 1.0 **그리고** B 3장 중 2장 린트 0 **그리고** B 토큰 ≤ A × 3. 셋 다 되면 스킬 「어느 길」 표에 「캐릭터 : PIL 고리도 됨」을 더한다. 하나라도 안 되면 고리는 「선택」으로 남기고 표는 안 고친다 |
| 기록 | `Docs/Research/2026-10-XX-draw고리실측.md` — 6장 비교판(`sheet --in a1 a2 a3 b1 b2 b3`) · 점수 표 · 바퀴별 린트 수 추이 |

## 14. 구현하며 바뀐 것 (2026-10-07)

본문(1~13절)은 그대로 두고, 구현하다 설계와 달라진 자리만 여기 모은다. **어긋나면 코드가 맞다.**

| 번호 | 자리 | 설계(본문) | 구현 | 까닭 |
| --- | --- | --- | --- | --- |
| ① | `lint.double` 정의 (3절) | 1px 선(불투명 이웃 ≤ 2) 위 같은 색 2×2 뭉침 | 같은 색 2×2 의 **둘레 12칸 중 같은 색이 1~4칸** | 원래 정의는 2×2 안에서 성립할 수 없다(2×2 칸마다 같은 색 이웃이 이미 3개) — 한 번도 안 걸린다 |
| ② | `metrics` (3절) | `symmetry` · `center` · `bbox` · `light_guess` | **`center_offset`**(질량 중심 − bbox 중심) 키 추가. 불투명 칸이 없으면 `symmetry` · `center` · `center_offset` · `bbox` 는 None | 본문 `center` 줄이 「차」를 같이 적었는데 키가 따로 필요했다 |
| ③ | `lint()` 인자 (3절) | `ramps` · `light` · `outline_mode` · `rules` · `waive` | **`axis_x`**(거울 축 x, 기본 그림 가운데) · **`outline_color`**(`solid` 선 색) 추가. `Canvas.lint` 도 같다 | `asym` · `symmetry` 가 가운데가 아닌 축을, `outline_gap` 이 `solid` 선 색을 알아야 한다 |
| ④ | `outline_gap` · `light_mismatch` (3절 끝) | 합친 그림으로 한 번 | 합친 그림으로 **한 번만** 재고 이슈의 `layer` 는 None. `light_mismatch` 는 `x` · `y` 도 None | 겹마다 재면 같은 가장자리를 겹 수만큼 센다 |
| ⑤ | `asym` 자동 켬 (12절 4번) | symmetry 켠 겹에서 자동 | **`rules=None` 일 때만** 자동. `rules` 를 직접 주면 그대로(모든 겹). CLI `lint` 는 symmetry 정보가 없어 자동으로 안 켜진다 — `--rules …,asym` | 사용자가 고른 규칙 목록을 몰래 바꾸지 않는다 |
| ⑥ | `changed()` (5절) | 실제로 값이 달라진 칸만 센다 | **`dirty` 기준**이라 칠했다 되돌린 칸도 센다. `count` · `bbox` · `layers` 모두 같은 기준 | `dirty` 는 칠할 때 값이 달라진 칸에 켜지고 `mark()` 때만 꺼진다. 처음 값과 끝 값을 따로 견주지 않는다 |
| ⑦ | `diff_grid` · `preview_changed` (5절) | 바뀐 영역 | **바뀐 칸이 없으면 거절**(`ArtToolError`) | 빈 bbox 로는 자를 창이 없다 |
| ⑧ | CLI 코드 자리 (8절) | `cli.py` 가 `grid` · `lint` 를 등록 | 등록만 `cli.py`, 실행은 **`draw/gridcmd.py`**(`grid show` · `grid apply`) · **`draw/lintcmd.py`**(`lint`) 로 나뉘었다 | 8절 파일 표에 없던 새 파일 둘. `lintcmd` 는 `gridcmd.open_input` 을 같이 쓴다 |
| ⑨ | 패키지 이름 | `arttool.draw.lint` 는 모듈 | `arttool.draw.__init__` 이 함수 `lint` 를 내보내, **`arttool.draw.lint` 속성은 함수를 가리킨다**(모듈이 가려진다). `from arttool.draw.lint import lint, LintResult` 는 된다 | `__all__` 에 `lint` 를 넣은 결과. 모듈 속성으로 `arttool.draw.lint.RULES` 를 쓰려면 `import` 문으로 부른다 |
| ⑩ | 소단계 크기 (11절 G2) | 구현 200줄 안 | G2 새 코드 **약 290줄**로 200줄을 넘었다 | 원본 보호 검사(`--out` 겹침 · 폴더 안 · 비어 있지 않은 폴더, PNG 입력은 감옥 · 덮어쓰기)가 `gridcmd.py` 를 키웠다 |
