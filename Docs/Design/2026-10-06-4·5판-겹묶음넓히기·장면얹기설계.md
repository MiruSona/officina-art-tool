### 4-1. 버전과 덧칸 `meta` (4-가)

지금 `from_dict` 는 `version != VERSION` 이면 거절하고(149행), 모르는 칸도 거절한다(`TOP_KEYS` 43행 · `LAYER_KEYS` 44행). 이 엄격함은 지킨다.

- **읽기** : `version` 1 · 2 둘 다 받는다. 1 인데 2 의 칸(`meta`·`size`·`offset`·`files`·사전 꼴 `items`)을 쓰면 거절 — 「version 2 로 올려라」 라고 적는다.
- **쓰기** (`save`) : 2 의 칸을 하나라도 쓰면 2, 아니면 1 로 쓴다. 옛 묶음을 읽고 다시 써도 1 그대로다.
- **옛 arttool 이 2 를 만나면** 지금 코드대로 「version 은 1 이다 : 2」 로 멈춘다. 조용히 틀리게 읽는 일은 없다. 이걸로 충분하다 — 따로 손대지 않는다.
- **`meta`** : 맨 위와 겹마다 둘 수 있는 자유 사전. **툴은 읽기만 하고 해석하지 않는다** (값 검사 없음, JSON 으로 쓸 수 있으면 된다). 피벗 · 메모 · 작업자 표시는 다 여기에. 옛 arttool 은 `meta` 를 모르는 칸으로 거절하므로 `meta` 도 버전 2 의 칸으로 센다(`meta` 만 써도 version 2).
- 앞으로 툴이 **해석하는** 칸은 이름 있는 칸 + 버전 올림, **해석하지 않는** 칸은 `meta` 아래. 이 갈래를 명령안내에 한 줄 적는다.
- 크기 한도 : `meta` 를 JSON 으로 펴서 64KB 넘으면 거절(실수로 그림 데이터를 넣는 일 막기).

### 4-2. 작은 겹 `size`·`offset` (4-가)

```json
{ "version": 2, "canvas": [64, 64],
  "layers": [
    { "name": "body" },
    { "name": "cheek", "size": [11, 11], "offset": [20, 30], "meta": { "pivot": [5, 5] } } ] }
```

- 둘은 함께 쓴다. 둘 다 없으면 지금처럼 캔버스 크기. `offset + size` 가 캔버스를 넘으면 거절.
- 그 겹의 그림은 모두 `size` 크기여야 한다. 아니면 지금 문구 꼴로 거절.
- **`read_item` 이 읽는 자리에서 투명 캔버스에 `offset` 으로 펴서 돌려준다.** 그 뒤 겹을 쓰는 명령(compose · mask · view · export)은 캔버스 크기 배열만 보므로 손대지 않는다.
- 단 **`read_item` 을 안 거치는 자리가 셋 있다** (10-06 코드 확인) : `layerops._read_raw`(133행, `check` 가 크기를 안 따지고 읽음) · `layerops` 717행(dry-run 읽기 목록) · `draw/canvas.py` 478·487행(겹 그림 쓰기 · 있나 보기). `_read_raw` 는 크기 비교를 canvas 대신 **그 겹의 `size`** 와 하고 편 배열을 돌려주게, 나머지는 새 `image_path` 시그니처로 고친다. `diff` 도 구현 때 읽는 길을 한 번 더 본다.
- 겹 그림을 **쓰는** 자리(`split` 의 겹 쓰기, `draw/canvas.py` 저장, 새 `layers fill`)는 쓸 때 상자로 잘라 쓴다. 상자 밖에 칸이 있으면 **거절**한다(경고가 아니다 — 4판-가 구현). `split` 과 `layers diff` 쓰기는 작은 겹 묶음을 아직 못 쓴다(거절).
- 그림마다 offset 이 다른 경우는 안 받는다(못 정한 것 1).

### 4-3. `layers check --cover <mask.png>` (4-가)

- 마스크 꼴 : 캔버스 크기 PNG, **알파 > 0 인 칸이 「덮여야 할 칸」**. `layers mask` 가 쓰는 마스크와 같은 꼴 — `frames bake --cover` 도 이 꼴이다.
- 그림마다 마스크 안에서 센다 : `empty`(어느 겹도 안 덮음) · `overlap`(둘 이상이 덮음, `exclusive_with` 와 상관없이 셈).
- `empty > 0` → 그 그림 실패, 경고 `cover_empty`. `overlap > 0` 은 경고만 `cover_overlap` (겹침이 뜻한 것일 수 있다). 종료 코드는 `check` 의 실패 규칙대로 4. 가림판 크기가 캔버스와 다르면 2.
- 보고는 그림 줄이 아니라 **맨 위 칸 `cover`** 의 그림별 목록 : `"cover": [{"item": "f03", "mask": "m.png", "cells": 812, "empty": 0, "overlap": 3}]`.

### 4-4. `layers fill` (4-가)

| 인자 | 기본 | 뜻 |
| --- | --- | --- |
| `--in <묶음>` | 꼭 | 겹 묶음 폴더 |
| `--mask <png>` | 꼭 | 4-3 꼴 마스크. 이 안의 **빈 칸만** 채운다 |
| `--nearest a,b,…` | 꼭 | 빈 칸을 붙일 후보 겹. 칸마다 **가장 가까운(체비셰프 거리) 불투명 칸을 가진 후보 겹**으로 간다. 거리 같으면 목록 앞 겹 |
| `--color #hex` | 없음 | 주면 이 색으로, 안 주면 그 가까운 칸의 색으로 |
| `--items a,b` | 전부 | 손볼 그림 |
| `--out <폴더>` | 꼭 | 새 묶음 폴더. **원본 묶음은 안 덮는다** (`layers.json` 도 함께 복사) |

- 처리 : 그림마다 `read_item` → 마스크 ∩ 빈 칸 → 후보 겹 거리 지도(numpy, 후보 수만큼) → 칸 배정 → 겹별로 쓰기(작은 겹은 4-2 대로 자름).
- 후보 겹 모두 그 그림에 없으면 그 그림은 건너뛰고 경고 `fill_no_target`. 작은 겹의 상자 밖 칸은 다음으로 가까운 겹이 채운다. 어느 겹도 못 채우는 칸만 비우고 경고 `fill_outside_box`.
- 보고 줄 : `{"item": "f03", "filled": {"ring": 41, "core": 7}}`. 맨 위에 가림판 이름 칸 `cover`(`mask` 가 아니다) · `nearest` · `color`.
- **2판 `fill --enclosed` 와의 갈래** : `fill --enclosed` 는 **낱장 하나**에서 **가장자리에서 번져 못 닿는 투명 칸**(틀에 갇힌 칸)을 한 색으로 채운다 — 영역을 그림이 정한다. `layers fill` 은 **겹 묶음**에서 **마스크가 정한 영역**의 빈 칸을 **어느 겹에 줄지** 정한다. 둘은 영역 고르는 법도, 쓰는 자리도 달라 이름 아래 묶음(`fill` 낱장 / `layers fill` 묶음)으로 가른다. 겹치는 코드는 없다.
- dry-run : `DRY_RUN_TAKES` (쓸 파일 목록을 보고).

### 4-5. 파일 무늬 `files` + 조합 `items` (4-나)

준비 #6 의 낱장들은 `<겹>/<그림>.png` 가 아니라 한 폴더에 `body_hop0.png` 처럼 놓여 있었다.

```json
{ "version": 2, "canvas": [48, 48],
  "layers": [
    { "name": "body", "files": "parts/body_{v}.png" },
    { "name": "face", "files": "parts/face_{v}.png", "size": [16, 10], "offset": [16, 12] } ],
  "items": [
    "idle",
    { "name": "hop0_smile", "pick": { "body": "hop0", "face": "01" } } ] }
```

- `files` : 묶음 폴더 기준 상대 경로 무늬. `{v}` 가 정확히 하나이고 **마지막 마디(파일 이름)에만** 있다 (`.png` 로 끝). 경로는 `paths.check_relative` · `safe_join` 으로 묶음 폴더 밖을 못 나간다. 없으면 지금처럼 `<겹>/<그림>.png`.
- **그 겹의 「변형」 목록** = 무늬에 맞는 파일들의 `{v}` 값. 이름 규칙은 그림 이름과 같다(`_check_name`).
- **겹 검사는 변형마다 따로** : 크기 · 색 수 · 팔레트 같은 낱장 검사는 겹 하나의 변형 각각에 돈다. 변형이 n·m 개여도 검사는 n+m 장이다.
- **조합은 `items` 에 적은 것만** : 사전 꼴 `{name, pick}` — `pick` 에 없는 겹은 그 그림에 없다(지금 「파일 없는 겹은 빠진다」 와 같다). 글자 꼴 `"idle"` 은 모든 겹에서 변형 이름 `idle` 을 고른 것과 같다(옛 뜻 그대로). **곱으로 모든 조합을 세지 않는다.**
- `pick` 의 값이 그 겹 변형에 없으면 거절. `pick` 에 적힌 겹이 `exclusive_with` 로 서로 막혀 있으면 거절.
- **달라진 것(구현)** : pick 이 고른 변형 파일이 없으면 `layers check` 는 거절이 아니라 경고 `layer_empty` 를 낸다(읽는 다른 명령은 거절). **`split` 은 변형 묶음에 그림을 더하지 않는다(거절)** — 남은 일.
- `image_path(folder, layer, item)` 은 `image_path(folder, layerset, layer, item)` 로 바뀐다(무늬 · pick 을 알아야 함). 부르는 자리를 모두 고친다(시험으로 다 잡힌다).
- `layers check` 보고에 `"variants": {"body": ["hop0", "idle"], "face": ["01", "idle"]}` 를 더한다. 어느 `items` 도 안 쓰는 변형은 경고 `unused_variant`. **구현에서는 「변형별 줄」 대신 경고 `variant_size`(크기가 겹과 다름) · `variant_alpha`(반투명 칸)로 냈다.**

### 4-6. `split` 색조 규칙 · `--gray-levels` (4-나)

- `RULE_KEYS`(30행)에 `hue` 를 더한다 : `{"hue": [200, 260], "to": "water"}` — HSV 색상(도) 범위, 0~360. `[340, 20]` 처럼 넘어가면 0 을 지나 감는다. 시작=끝이면 거절한다. `color` 와 `hue` 는 규칙 하나에 하나만 쓴다.
- 덧칸 `min_sat`(기본 0.15) : 채도가 낮은 칸(회색 · 검정)은 색상이 흔들리니 `hue` 규칙에서 뺀다.
- 규칙 순서 · 「먼저 맞은 규칙이 가진다」 는 지금 그대로. `hue` 는 `box`·`above_y` 같은 자리 규칙과 함께 쓸 수 있다.
- `--gray-levels 255,220,180` : 겹으로 나눈 **뒤** 칸마다 밝기를 가장 가까운 단계 회색으로 바꾼다(알파 그대로). 「밝기 위에 색 입히기」 밑판용. 0~255, 2개 이상, 겹치면 거절.
- 하나도 안 맞은 불투명 칸은 지금 경고를 그대로 쓴다.

### 4-7. `frames bake` (4-다)

P8 : 프레임마다 ① 발 줄 맞추기 ② 정한 칸을 기준 그림으로 덮기 ③ 같은 상자로 자르기 ④ 띠 ⑤ gif. 지금은 ①이 `normalize`, ④가 `sheet` 에 흩어져 있고 ②는 없다.

| 인자 | 기본 | 뜻 |
| --- | --- | --- |
| `--in <폴더>` | 꼭 | 프레임 PNG 폴더. 이름 순서 = 프레임 순서 (자연 정렬 : `f2` < `f10`) |
| `--out <폴더>` | 꼭 | 구운 프레임 폴더 (같은 이름) |
| `--foot <y>` · `--foot auto` | 안 함 | 맨 아래 불투명 줄을 y 로 맞춘다. `auto` 는 첫 프레임의 발 줄. 찾는 함수는 `normalize` 의 것을 같이 쓴다 |
| `--cover <mask.png>` | 안 함 | 4-3 꼴 마스크. 알파 > 0 칸을 `--cover-from` 그림의 같은 칸으로 덮는다 (알파 포함 통째) |
| `--cover-from <png>` | 발 줄을 맞춘 뒤의 첫 프레임 | 덮을 기준 그림. 프레임과 같은 크기. `--cover` 가 있을 때만 쓴다 (구현 4-다) |
| `--crop x,y,w,h` · `--crop union` | 안 함 | 모든 프레임을 같은 상자로. `union` 은 모든 프레임의 불투명 상자를 합친 것 |
| `--strip <png>` | 안 함 | 가로 띠 한 장 |
| `--gif <gif>` · `--duration 110` · `--loop 0` | 안 함 | 움직이는 gif. `--duration` · `--loop` 은 `--gif` 가 있을 때만 쓴다 (구현 4-다) |
| `--scale N` | 1 | 띠 · gif 만 키운다(프레임 PNG 는 원래 크기). 1~64 (구현 4-다) |

- 처리 순서는 위 ①~⑤ 고정. 순서를 바꾸는 인자는 없다 — 발 줄을 맞춘 뒤 덮어야 마스크 자리가 프레임마다 같다.
- 발 줄을 옮기다 캔버스 밖으로 나가는 칸이 있으면 경고 `frames.foot_clipped`. 프레임 크기가 서로 다르면 `UsageError`.
- `--cover` 가 바꾼 칸 수를 프레임마다 보고 : `{"name": "f03", "shift_y": -1, "covered": 57}`. `covered` 는 덮어서 **값이 실제로 바뀐** 칸만 센다 (구현 4-다).
- **gif · 띠는 `image.save_gif` · `image.strip` 을 쓴다** (구현 4-다). 2판이 이미 만들어 둔 공용 함수라 `gifout.py` 는 만들지 않았다. 투명은 팔레트 한 칸을 투명색으로, 알파는 0/255 로 끊는다(반투명 칸은 경고 `frames.gif_alpha_cut`).
- 프레임 상한 512장 (구현 4-다). 넘으면 거절.
- 새 묶음 `frames` 를 만들고 그 밑 첫 명령이 `bake`. 파일 `src/arttool/frames/bake.py`.
- dry-run : `DRY_RUN_TAKES`. 보고 `out` 은 `{"frames": "...", "strip": "...", "gif": "..."}`.

## 5판 — 장면 얹기 · 목업 합성

### 장면

| 근거 | 막힌 일 | 이번 답 |
| --- | --- | --- |
| 아이콘 #7 | 진열장 좌표에 아이콘을 얹어 판 셋을 견줌 (PIL) | `sheet --on --at` · 여러 자리는 `ui mockup` |
| 농장 「막힌 것」 19행 | 잔디 타일 위에 지금 / 고친 뒤를 나란히 | `sheet --bg <png>` |
| 가게 「없어서 PIL 로 한 것」 33행 | 화면 캡처에서 스프라이트 자리를 찾아 고친 그림을 덧대 봄 | `sheet --on` + 뒤 덩이 `--find` |
| 목업 v4 (9 · 78행) | 글자를 마지막에 한꺼번에 찍어 종이 패널 위로 뒤 화면 글자가 비침 | `ui mockup` — 글자도 겹 순서를 가진다 |

### 5-1. `sheet --bg <png>` (5-가, S)

- `--bg` 값 읽기 : `checker` → 지금대로, `#` 로 시작 → 단색, 그 밖 → PNG 경로. 파일이 없으면 `UsageError` (「checker · #RRGGBB · PNG 경로 중 하나」). `cli.py` 298행 도움말 · `sheet.py` 67행 문구를 고친다.
- 타일 PNG 는 칸(셀) 크기만큼 왼쪽 위부터 되풀이 깔고, **칸과 같은 배율로 키운다** — 도트 격자가 맞는다.
- 칸마다 타일 시작점이 같다(모든 칸에서 같은 무늬 → 견주기 쉬움).
- 반투명 타일은 체크무늬 위에 먼저 깐다. 보고 `bg` 에 경로를 그대로 적는다.

### 5-2. `sheet --on <png> --at x,y` (5-가, M)

- `--on` : 장면 그림(진열장 · 화면 캡처). `--at` : 그 그림 위 원래 픽셀 좌표. 입력 그림 **하나하나가 장면 사본 한 장에 얹혀 칸 하나가 된다** — 「지금 / 고친 뒤」 가 같은 장면에서 나란히 보인다.
- 얹기는 알파 합성(`over`). 칸 크기 = 장면 크기. 배율 · 띠 · 이름표는 지금 `sheet` 그대로.
- `--crop x,y,w,h` 를 함께 주면 장면에서 그 상자만 보여 준다(큰 캡처에서 둘레만).
- 얹은 그림이 장면(또는 `--crop` 상자) 밖으로 나가면 잘리고 경고 `on_clipped` (**구현**: `sheet.` 앞머리 없음).
- **구현**: `--crop` 상자 자체가 장면 밖이면 거절(종료 2). `--strip` 과 같이 줘도 거절.
- `--on` 이 있으면 `--bg` 는 장면 아래(투명 칸)에만 깔린다.
- **한 장면에 여러 자리(아이콘 #7 의 진열장 칸 여럿)는 `ui mockup` 몫이다.** `sheet --at` 을 여러 개 받게 하면 「입력 몇 번이 자리 몇 번」 짝 규칙이 생겨 헷갈린다.

### 5-3. `sheet --find <old.png>` (5-가 뒤 덩이)

- 가게 33행 하나뿐이라 뒤에 둔다. `--at` 대신 쓴다 : 장면에서 `old.png` 의 불투명 칸이 **정확히 같은** 자리를 찾아 `--at` 으로 쓴다(알파 0 칸은 비교 안 함).
- 0곳 → `UsageError`. 둘 이상 → 첫 자리를 쓰고 경고 `find_many` (자리 목록 20개까지. **구현**: `sheet.` 앞머리 없음). 10초 안에 못 끝내면 실패한다.
- 찾은 자리의 옛 그림은 **지우지 않고 그 위에 새 그림을 얹는다.** 새 그림이 옛 그림을 다 덮지 못하면 옛 칸이 남아 보인다 — 바뀐 칸만 바꾼 PIL 판과 같은 결과다. 옛 칸을 지우려면 `--find-clear` (옛 불투명 칸을 먼저 투명으로 비운 뒤 `--bg` 를 깔고 얹음)를 준다. **구현**: `--find-clear` 는 아직 안 했다(남은 일).
- 크기 64×64 그림 · 1920×1080 장면을 numpy 로 무식하게 찾아도 1초 안쪽이라 본다(구현 때 잰다).

### 5-4. `ui mockup` (5-나, L)

이름은 `ui` 묶음 밑 `ui mockup`. 9조각(`ui/ninepatch.py`) · 글꼴(`ui/glyphs.py`)을 다시 쓰니 같은 묶음이 맞다.

**장면 파일**

```json
{ "version": 1,
  "canvas": [320, 180],
  "background": { "image": "bg/grass.png", "tile": true },
  "fonts": { "body": { "file": "fonts/pixel.ttf", "size": 8 } },
  "nodes": [
    { "kind": "image", "src": "shop/shelf.png", "at": [0, 40], "z": 0 },
    { "kind": "image", "src": "icons/apple_v2.png", "at": [24, 52], "scale": 1, "z": 10 },
    { "kind": "panel", "src": "ui/paper.9.png", "at": [180, 20], "size": [120, 80], "mode": "stretch", "z": 20 },
    { "kind": "text", "text": "사과 3개", "font": "body", "at": [190, 30], "color": "#3A2A1E", "z": 21 } ] }
```

- `kind` 셋 : `image`(그림) · `panel`(`.9.png` 을 `slice_stretch` 로 늘림, `mode` 는 `stretch`·`tile`) · `text`(글자).
- **그리기 순서 = `z` 오름차순, 같으면 적은 순서.** 글자도 이 순서 안에서 찍는다 — 목업 v4 의 「패널 위로 뒤 글자가 비침」 이 구조로 안 생긴다.
- `scale` : 정수 1~8, 가까운 이웃 키우기. `at` 은 캔버스 픽셀 좌표(키운 뒤 그림의 왼쪽 위).
- `background` : `#hex` 글자 · `{image, tile}` · 없음(투명).
- **글자** : `glyphs.load_font(file, size)` 로 읽고 PIL 로 그린 뒤 **알파를 0/255 로 끊는다**(도트 화면이라 흐린 가장자리 금지). `find_missing` 으로 빠진 글자를 찾으면 경고 `ui_mockup.missing_glyph` (글자 목록) — 목업에서도 `ui glyphs` 와 같은 검사가 돈다. 줄바꿈은 `\n` 만, 자동 줄바꿈은 없다. 덧칸 `align`(`left`·`center`·`right`, 기본 left).
- **경로 감옥** : `src` · `file` · `background.image` 는 모두 **장면 파일이 있는 폴더 기준 상대 경로**. `paths.check_relative` 로 절대 경로 · `..` 탈출을 거절하고 `safe_join` 으로 연다. 장면 파일 하나로 디스크 아무 곳이나 읽게 하지 않는다.
- 모르는 칸은 거절(`layers.json` 과 같은 엄격함). 해석 안 하는 메모는 `meta`.
- 그림이 캔버스 밖으로 나가면 잘리고 경고 `ui_mockup.clipped` (노드 번호).

| 인자 | 기본 | 뜻 |
| --- | --- | --- |
| `--scene <json>` | 꼭 | 장면 파일 |
| `--out <png>` | 꼭 | 목업 PNG |
| `--scale N` | 1 | 다 그린 뒤 통째로 키움(보여 주기용) |
| `--set id=src` (여럿) | 없음 | 노드에 `"id"` 를 달아 두고 그 `src` 만 바꿔 그림 — 「판 셋 견주기」 를 장면 파일 셋 없이 |

- **구현**: 글자는 `glyphs.render_line` 을 새로 꺼내지 않고 이미 있는 `image.text_mask` 로 그린다.
- **구현**: `--set` 에 장면에 없는 id 를 주면 거절(종료 2). 같은 id 를 두 번 줘도 거절.
- **구현 상한** (넘으면 거절) :

| 대상 | 상한 |
| --- | --- |
| 장면 파일 | 256KB |
| 노드 · 글꼴 · `--set` | 512 · 16 · 64 |
| 캔버스 · 패널 한 변 | 4096 |
| `at` 절댓값 | 4096 |
| 노드 `scale` · `--scale` | 8 · 16 |
| 글꼴 크기 · 글자 한 노드 | 256 · 1024자 |

- 보고 : `{"version":1,"status":"ok","scene":"…","canvas":[320,180],"nodes":4,"drawn":[{"i":0,"kind":"image","z":0},…],"warnings":[],"out":"mock.png"}`.
- 종료 코드 : 0 정상 · 2 인자/장면 꼴 잘못(`UsageError`) · 1 은 쓰지 않는다(검사 명령이 아님).
- dry-run : `DRY_RUN_TAKES` (장면을 다 검증하고 쓸 파일만 보고).
- 아이콘 #7 은 `--set` 으로 푼다 : 장면 하나 + `--set slot1=icons/v1/apple.png …` 을 세 번 → 세 장을 `sheet` 로 나란히.

## 못 정한 것

1. **그림마다 다른 offset** (같은 볼 겹이 프레임마다 자리를 옮김). 지금 근거가 없어 겹마다 하나로 둔다. 필요해지면 `pick` 옆에 `"offset": {"cheek": [x, y]}` 를 더하는 길이 있다.
2. **2판과 4-다의 순서.** 2판 `tint --gif` · `sheet --strip` 이 먼저 들어오면 4-다가 그 함수를 쓴다. 4-다가 먼저면 4-다가 공용 함수를 만들고 2판이 따른다 — 어느 쪽이 먼저인지는 일정이 정한다.
3. **`layers fill` 에 마스크 대신 「갇힌 칸」 고르기**(`--enclosed`)를 줄지. 지금은 근거가 마스크 하나뿐이라 안 넣었다.
4. **`ui mockup` 자동 줄바꿈 · 글자 테두리.** 목업 v4 근거엔 없어서 뺐다.
5. `--find` 의 「정확히 같은」 이 압축 캡처(jpg)에서 못 찾을 수 있다. 근거가 PNG 캡처라 허용 오차는 안 뒀다.
